Often one graph tells a better story than a thousand data points. Yet sometimes the truth is really in a single number.

Deepview caters to this by making it possible to add aggregates to your project.

{/* Screenshot: aggregate plot added to a project */}

There are three formats in which you can add aggregates to your project:

- **Table format** — useful to show a set of data along two variables
- **Number format** — useful to show a single number
- **Bar format** — similar to the table format but more visual

## Get started

Click **Add Plot** and select the aggregate format you want to add.

{/* Screenshot: aggregate format options in the Add Plot dialog */}

## Edit aggregate

Whichever aggregate format you chose, click the settings wheel at the top-right of the plot to edit how the aggregate is calculated.

{/* Screenshot: aggregate settings wheel */}

## Aggregate method

In the edit screen, you can select the method used to calculate the aggregate. Currently available:

- Average
- Minimum
- Maximum
- Sum
- Count

## Filter

In the filter section, you can define the conditions under which the metric is calculated.

Setting a filter is optional. If you define multiple filters, they all need to be true — filter1 AND filter2 must both be true for a data point to be included in the aggregate.

## Group by

If you want the aggregate to be a table or a bar chart, select a signal to group the calculation by. To add a signal, drag and drop it from the Signal List.

There are two ways to group the data:

- **Unique** — creates a group for each unique value in the signal; great for discrete or text signals
- **Bins** — manually define the **bin range** (the range of the signal's y-axis values to include) and the **bin size** (the unit by which the range is divided); useful for continuous signals

Consider the following example: if the aggregate format is a bar chart, and the aggregate is the average of the engine temperature (`avg(m.engine.temperature)`), you get a bar chart showing the distribution of the average engine temperature per cycle.

{/* Screenshot: bar chart of average engine temperature per cycle */}

If you want to see the average engine temperature depending on the engine speed, group by the engine speed signal and set the bin limits and width accordingly.

{/* Screenshot: grouping by engine speed with bin limits and width configured */}

{/* Screenshot: resulting bar chart of average engine temperature per engine speed bin */}

You can also resample the different input signals, so you can use signals with different time bases together. See [Resampling](/deepview/analysis/resampling) for more details.

## Bar settings

If you chose a bar chart to visualize your aggregate, you can also set the width of the bars as a share of the available space.
