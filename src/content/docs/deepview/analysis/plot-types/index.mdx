Deepview has eight plot types:

- [Time Series](/deepview/analysis/plot-types/time-series)
- [Scatter](/deepview/analysis/plot-types/scatter)
- [Map](/deepview/analysis/plot-types/map)
- [Frequency (FFT)](/deepview/analysis/plot-types/frequency-fft)
- [Heatmap](/deepview/analysis/plot-types/heatmap)
- [Metadata](/deepview/analysis/plot-types/metadata)
- [State](/deepview/analysis/plot-types/state)
- [Message](/deepview/analysis/plot-types/message)

You can also add aggregate views to your plot.

- [Aggregates](/deepview/analysis/plot-types/aggregates)

## Add a plot to your project

If you start a new project, or a new tab within an existing project, you're prompted to select a plot type.

{/* Screenshot: plot type selection prompt for a new project or tab */}

To add a plot to an existing tab, click the **Add Plot** button at the top-right of your screen.

{/* Screenshot: "Add Plot" button at the top-right of the screen */}
