## Add data to an empty project

Click **Add data**, then find and select the data you want in the data library — see [Selecting Data](/deepview/database#selecting-data).

{/* Screenshot: empty project with the "Add data" button visible */}

## Add more data to a project that already has data

1. Go to the data library
2. Find and select the data you want to load
3. Click **Visualise** in the bottom-right corner

{/* Screenshot: data library with a data set selected and "Visualise" visible */}

## Switch between loaded data sets

The bottom-left of the screen shows which data set is currently loaded. Click the dropdown to switch to a different one, or use the left/right arrows in the same panel.

{/* Screenshot: bottom-left dataset dropdown with left/right arrows */}

Press <kbd>i</kbd> (or click **Manage layers**) to open the **Manage layers** dialog. From there you can:

1. Select which loaded data set to visualize
2. Change the order of the data sets
3. Add more data
4. Remove a data set you've loaded

{/* Screenshot: "Manage layers" dialog */}
