There are two ways to export a plot:

- Export a single plot
- Export multiple plots from a project in bulk

## Export a single image

To save a static image of your current visualization for use in another context, use the export plot feature in the toolbar above the plot.

![](../../../../assets/images/deepview/deepview-analysis-export-image-1.png)

A dialog then opens where you can configure the image you're exporting:

- General settings — filename, zoom, figure size, dark mode, enable/disable cursors, time zone
- Plot-specific settings, depending on your plot type

Save your export settings (bottom left) to reuse them later or in a bulk export.

![](../../../../assets/images/deepview/deepview-analysis-export-image-2.png)

## Bulk export

Export multiple plots from a project — for example, to reuse them in another reporting tool — by clicking the export button in the top-left.

![](../../../../assets/images/deepview/deepview-analysis-export-image-3.png)

Set general settings and select the plots to include in your export. The download contains a `.zip` file with an export of all selected plots.

![](../../../../assets/images/deepview/deepview-analysis-export-image-4.png)
