title: "Export image"
description: "Save a static image of your visualization, with configurable fonts, signals, title, and gridlines."
sidebar:
  order: 11
---

To save a static image of your current visualization for use in another context, use the export plot feature in the toolbar above the plot.

{/* Screenshot: export plot button in the toolbar */}

A dialog then opens where you can configure the image you're exporting. You can set:

- The font size of the legend
- The font size of the axes
- Which signals to show on the plot
- Whether to show a title
- Whether to show gridlines
