Switch to **Functions** in the signal list to see all functions currently added to your project. Use the search bar at the top to find one quickly.

![](../../../../../assets/images/deepview/deepview-analysis-functions-functions-overview-1.png)

## Add a function to your project

Same as adding a signal: double-click it, or drag and drop it onto a plot.

![](../../../../../assets/images/deepview/deepview-analysis-functions-functions-overview-4.gif)

## Function library

Click **Browse** to open the **Function Library** — an overview of every function created in your workspace.

![](../../../../../assets/images/deepview/deepview-analysis-functions-functions-overview-3.png)

Search or filter it using the search bar and filter icon at the top of the dialog.

![](../../../../../assets/images/deepview/deepview-analysis-functions-functions-overview-2.png)

## Create a new function

Click **Create** in the bottom-left of the Function Library dialog. See [Built-in functions](/deepview/analysis/functions/built-in-functions) and [Custom functions](/deepview/analysis/functions/custom-functions) for the two ways to define one.

![](../../../../../assets/images/deepview/deepview-analysis-functions-functions-overview-5.png)
