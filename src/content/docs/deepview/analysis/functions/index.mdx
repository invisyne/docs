Beyond visualizing raw signals, you can apply functions to signals — or combinations of signals — to create custom variations. This lets you run calculations on the fly and tailor the analysis to your needs, without touching the original data set.

- [Functions Overview](/deepview/analysis/functions/functions-overview) — where to find and add functions in the interface
- [Built-in functions](/deepview/analysis/functions/built-in-functions) — the ready-made functions available out of the box
- [Custom functions](/deepview/analysis/functions/custom-functions) — writing your own
