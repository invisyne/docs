## 3.8.0

*2026-07-13*

### Highlights

> Deepview 3.8 adds figure export with extended options and batch exporting, and fixes several authentication and reporting issues.

---

### New Features

- **Export figures** — Extended export options (filename, zoom, pixels, dark mode, cursors, time zone, segments), the ability to edit plot settings before exporting, and saved export settings.
- **Batch export figures** — Export figures from multiple projects, tabs, and plots at once, using shared general settings (export settings and full-range/zoom-range).

### Bug Fixes

- **Authentication via Entra ID & Cognito** — Custom logout redirects are now supported, and expired token refresh no longer fails.
- **Reports** — Fixed reports that were failing to generate, and fixed the automation token disappearing when pressing Escape.

## 3.6.0

*2026-05-27*

### Highlights

---

### New Features

- **Analysis** — A configurable legend position for Time Series plots (sidebar, floating, below, or hidden), an improved "organise data sets" dialog, and an improved "restore session" dialog.

## 3.5.0

*2025-05-12*

### Highlights

> Deepview 3.5 introduces automated reporting — reports can now be generated and delivered automatically whenever new data arrives.

---

### New Features

- **Automated reports** — Automatically generate a report whenever a new data set is uploaded, and receive it by email, Slack, or Teams. Report layouts can now use columns, support undo/redo (Ctrl+Z/Y), and confirm when a template is saved.

### Bug Fixes

- **Analysis** — Fixed missing annotations when loading multiple data sets, fixed annotations not being removed when the user who created them is deleted, stopped adding signals to a plot when opening or closing a signal group, and improved the display of State plots in overlay mode.
- **Database** — Data set sorting is now remembered, and fixed the "default columns" connection setting.
- **Overview Dashboards** — Added a color legend to Scatter plots, fixed a white screen on dashboards with many Scatter plots, and dashboard owners can now reset the metric cache.

## 3.4.0

*2026-04-17*

### Highlights

> Deepview 3.4 adds full-featured Reports across all plot types, a new InfluxDB 2 connection, and several Overview Dashboard and export improvements.

---

### New Features

- **Reports** — Support for all plot types, plots in generated PDFs now link back to the corresponding project, templates can combine plots from multiple projects, and plot configuration is saved with the report.
- **Overview Dashboards** — Sort bar, pie, and table charts; first/last aggregate functions; clear failed values.
- **InfluxDB 2 connection**
- **Frequency (FFT) plot smoothing**
- **Custom map tile servers**
- **Open plots in full screen**
- **Choose the timestamp unit when exporting data**

### Bug Fixes

- Fixed function signals in Trino connections.
- Improved live cursor stability.
- Faster loading for large Overview Dashboards.
- Constant or empty signals are now hidden in the signal list.
- Various report layout and performance fixes.
- License page improvements.
