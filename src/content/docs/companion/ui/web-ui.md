## **Access to the WebUI**

- **Direct access to configuration:** The Crawler.Companion offers a button (e.g., a globe or browser icon) through which the customer can launch the WebUI (Web User Interface) of the selected Edge (Crawler) device directly from the application.
- **Quick connection:** This saves manually entering the IP address in the browser and enables quick switching to detailed, browser-based management of the device.
