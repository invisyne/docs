import exportImg from '../../../../assets/images/companion/companion-export-panel.png';

The **Export** tab lets you export measurement data from an Edge device — either as a CSV file or directly to Deepview. Select a device in the list and click the **Export** tab in the detail panel.

:::note
The Deepview option is only available when your Hub account has Deepview access enabled. If it is grayed out, contact your administrator.
:::
