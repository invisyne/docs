Clicking a device in the list opens the detail panel on the right. It contains four tabs: **Details**, **Netzwerk Einstellungen**, **Update**, and **Export**.

  <img src="/images/companion/geraete-detailansicht-neu.png" alt="Crawler.Companion device detail panel — Details tab" />
</div>

<div class="qs-stepper">

  <div class="qs-tabbar">
    <a class="qs-tab" href="#">General</a>
    <a class="qs-tab" href="#">System</a>
    <a class="qs-tab" href="#">Firmware</a>
  </div>

  <div class="qs-panels">

    <div class="qs-panel">

      | Field | Description |
      |-------|-------------|
      | **BMK/OKZ** | Device name as configured on the Edge device. |
      | **WebUI** | Indicates whether the device's web interface is reachable. Click **WebUI** to open it in the browser. |

    </div>

    <div class="qs-panel">

      | Field | Description |
      |-------|-------------|
      | **Type** | Hardware platform, e.g. VMware Virtual Platform, Crawler Core. |
      | **Seriennummer** | Unique identifier of the device hardware. |
      | **MAC-Adresse 1** | MAC address of the X1 network adapter. |
      | **MAC-Adresse 2** | MAC address of the X2 network adapter, if present. |

    </div>

    <div class="qs-panel">

      | Field | Description |
      |-------|-------------|
      | **Version** | Currently installed firmware version. |
      | **Letztes Update** | Date and time of the last firmware update. |

    </div>

  </div>

</div>
