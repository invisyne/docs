The **Netzwerk Einstellungen** tab of the detail panel lets you configure how an Edge device connects to the network.

<div class="screenshot-frame">
  <img src="/images/companion/geraete-netzwerkeinstellung.png" alt="Crawler.Companion — Network Settings tab" />
</div>

<div class="qs-stepper">

  <div class="qs-tabbar">
    <a class="qs-tab" href="#">DHCP</a>
    <a class="qs-tab" href="#">Static IP</a>
  </div>

  <div class="qs-panels">

    <div class="qs-panel">

      | Field | Description |
      |-------|-------------|
      | **Use as primary adapter** | Determines which port Companion uses to communicate with the device. |
      | **Configuration mode** | Set to DHCP — the device receives its IP address automatically from the network. |
      | **DNS server** | Optional. Used for name resolution. |
      | **Save** | Applies the settings. |

    </div>

    <div class="qs-panel">

      | Field | Description |
      |-------|-------------|
      | **Use as primary adapter** | Determines which port Companion uses to communicate with the device. |
      | **Configuration mode** | Set to Static IP — enter a fixed address manually. |
      | **IP address** | Unique network address of the device. |
      | **Subnet mask** | Defines the address range of the local network. |
      | **Gateway** | Router address for communication outside the local network. |
      | **DNS server** | Optional. Used for name resolution. |
      | **Save** | Applies the settings. |

    </div>

  </div>

</div>

For a step-by-step guide on configuring network settings, see [Initial Setup](/companion/how-to/initial-setup).
