## Installation

Crawler.Companion does not require a traditional installation. Download the `.exe` file from the Hub and run it directly.

<Steps>

1. **Open Hub → Software**

   Navigate to the **Software** section in your Hub and locate the Companion version you want to use. Click **Downloads und Details**.

   <div class="screenshot-frame">
     <img src="/images/companion/companion_download.png" alt="Hub Software page with Companion version" />
   </div>

2. **Download the file**

   On the version detail page, click the **Download** button on the right side. A ZIP archive (e.g. `crawler.companion-v1.2.0.zip`) will be saved to your computer.

   <div class="screenshot-frame">
     <img src="/images/companion/companion_download_button.png" alt="Download button on the version detail page" />
   </div>

3. **Extract and run**

   Extract the ZIP archive and double-click the `.exe` file inside.

   <div class="screenshot-frame">
     <img src="/images/companion/companion_exe.png" alt="Extracted companion exe file" />
   </div>

4. **Confirm the Windows security prompt**

   Windows SmartScreen may block the launch. Click **Weitere Informationen** (More info).

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src="/images/companion/companion_windows_warning.png" alt="Windows SmartScreen warning" />
   </div>

   Then click **Trotzdem ausführen** (Run anyway) to start Companion.

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src="/images/companion/companion_windows_warning_expanded.png" alt="Windows SmartScreen expanded with Run anyway button" />
   </div>

5. **Companion opens**

   Crawler.Companion is now running. Connect your PC to the same local network as the Edge devices and use the search function to discover them.

</Steps>
