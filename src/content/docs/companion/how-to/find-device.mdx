Crawler.Companion automatically scans the local network for Edge devices when it starts. No manual configuration is required to find a device.

<Steps>

1. **Connect to the same network**

   Make sure your PC is connected to the same local network (subnet) as the Edge devices you want to find.

2. **Open Companion**

   Launch Crawler.Companion. It immediately begins scanning for devices — no further action is needed.

3. **Check the device list**

   All discovered Edge devices appear in the main device list with their name, hardware type, firmware version, and network information.

   Unconfigured devices are shown with status **N/A** — they can be selected and configured directly from here.

   <div class="screenshot-frame">
     <img src="/images/companion/companion-devices-list.png" alt="Companion device list showing discovered Edge devices" />
   </div>

4. **Select a device**

   Click any row to open the device detail panel on the right side.

</Steps>

:::note
If a device does not appear, check that it is powered on and connected to the same subnet as your PC. Devices on a different subnet are not reachable via local network scan.
:::
