When a new Edge device is connected to the network, Crawler.Companion detects it automatically. Before the device can be used, it needs a network address that is reachable from your PC. This guide walks you through setting that up.

<div class="ht-note-block">
  <p>The full device setup (Hub connection, sensors, configuration) is done via the Edge web interface using the Setup Wizard — not through Companion. Once the network settings are saved here, follow the <a href="/edge/how-to/initial-setup">Edge Initial Setup</a> guide to complete the process.</p>
</div>

<div class="ht-phase-steps">

  <div class="ht-phase-label">Find the device</div>

  <Steps>

  1. **Open Companion**

     Launch Crawler.Companion. It scans the network automatically. New devices appear in the device list with the status **Einrichtung erforderlich**.

     <div class="screenshot-frame">
       <img src="/images/companion/einrichtung-erforderlich.png" alt="Device list showing a device with status Einrichtung erforderlich" />
     </div>

  2. **Select the device**

     Click on the device to open its detail panel.

  </Steps>

  <div class="ht-phase-cont-2">

    <div class="ht-phase-label">Configure network</div>

    <Steps>

    1. **Open the Network Settings tab**

       Click the **Netzwerk Einstellungen** tab in the detail panel.

    2. **Choose an IP mode**

       Select **DHCP** (IP assigned automatically by your router) or **Statische IP** (fixed IP address).

    3. **Enter network values** *(Static IP only)*

       If you selected **Statische IP**, fill in:

       - **IP-Adresse** — e.g. `192.168.1.50`
       - **Subnetzmaske** — e.g. `255.255.255.0`
       - **Gateway** — e.g. `192.168.1.1`

    4. **Save the configuration**

       Click **Speichern**. The device applies the new network settings.

    </Steps>

  </div>

</div>

Once the device is reachable at its new address, open the Edge web interface and run the Setup Wizard to complete the initial configuration — see [Edge Initial Setup](/edge/how-to/initial-setup).
