Crawler.Companion does not require a traditional installation. Download the `.exe` file from the Hub and run it directly.

<Steps>

1. **Hub login → Software**

   Log in at [hub.invisyne.com](https://hub.invisyne.com) and navigate to the **Software** section. Locate the Companion version you want to use and click **Downloads und Details**.

   <div class="screenshot-frame">
     <img src={downloadPageImg.src} alt="Hub Software page with Companion version" />
   </div>

2. **Download the file**

   On the version detail page, click the **Download** button on the right side. A ZIP archive (e.g. `crawler.companion-v1.2.0.zip`) will be saved to your computer.

   <div class="screenshot-frame">
     <img src={downloadButtonImg.src} alt="Download button on the version detail page" />
   </div>

3. **Extract and run**

   Extract the ZIP archive and double-click the `.exe` file inside.

   <div class="screenshot-frame">
     <img src={exeImg.src} alt="Extracted companion exe file" />
   </div>

4. **On Windows: confirm the security prompt**

   Windows SmartScreen may block the launch. Click **Weitere Informationen** (More info).

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src={warningImg.src} alt="Windows SmartScreen warning" />
   </div>

   Then click **Trotzdem ausführen** (Run anyway).

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src={warningExpandedImg.src} alt="Windows SmartScreen expanded with Run anyway button" />
   </div>

5. **Companion opens**

   Crawler.Companion is now running.

</Steps>
