    <p class="page-hero-lead">Crawler.Companion is a Windows desktop application for managing Edge devices on the local network. <div class="page-hero-body">
  <p>Companion is particularly useful in closed networks without internet access, where devices cannot be managed through Hub. In these environments, Companion provides all configuration and management capabilities entirely over the local network.</p>

<div class="companion-intro">

  <p class="companion-intro-lead">Initial configuration of Edge devices on the local network.</p>
  <p class="companion-intro-body">The device list shows all Edge devices in the local network — including devices that are already configured as well as new devices that have not yet been set up. Unconfigured devices can be assigned their first network configuration directly from here.</p>

## Functional Scope

<div class="feature-grid">
  <div class="feature-card">
    <div class="feature-card-title">Device Discovery</div>
    <p>Finds all Edge devices in the local network — including unconfigured devices with no known IP address.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Initial Configuration</div>
    <p>Assigns a first network configuration to newly discovered Edge devices.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Network Settings</div>
    <p>Adjust and export network settings for multiple devices without accessing each device's web interface individually.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Software Updates</div>
    <p>Install firmware updates on Edge devices directly from Companion.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Data Export</div>
    <p>Export data from Edge devices — especially useful in closed local networks.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Bulk Management</div>
    <p>Manage multiple Edge devices simultaneously instead of accessing each web interface individually.</p>
  </div>
</div>

## Safety Notes

<div class="security-grid">
  <div class="security-item">
    <div class="security-item-title">Network Changes</div>
    <p>Incorrect network settings can make devices unreachable. Only edit these if you are familiar with IP addresses and subnet masks.</p>
  </div>
  <div class="security-item">
    <div class="security-item-title">Updates</div>
    <p>Ensure stable power supply to the Edge device before installing updates.</p>
  </div>
  <div class="security-item">
    <div class="security-item-title">Same Network Required</div>
    <p>Your PC must be in the same local network as the Edge devices.</p>
  </div>
</div>
