## Users <span class="howto-admin-badge">Admin only</span>

<div class="qs-stepper">
  <div class="qs-tabbar">
    <a class="qs-tab" href="#">Invite User</a>
    <a class="qs-tab" href="#">Change Role</a>
  </div>
  <div class="qs-panels">

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Create a New User</div>
        <p class="howto-card-desc">Create a new user account in Hub and assign a role.</p>
        <ol class="howto-steps-preview">
          <li>Go to <strong>Users</strong> in the top navigation bar.</li>
          <li>Click the <strong>+</strong> button.</li>
          <li>Enter the new user's email address.</li>
          <li>Select a role: <strong>Admin</strong> or <strong>User</strong>.</li>
          <li>Click <strong>Create</strong> — the account is active immediately.</li>
        </ol>
        <a href="/hub/how-to/invite-user/" class="howto-cta">Full guide →</a>
      </div>
    </div>

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Change a User's Role</div>
        <p class="howto-card-desc">Promote a User to Admin or downgrade an Admin to User — the change takes effect at the user's next page load.</p>
        <ol class="howto-steps-preview">
          <li>Go to <strong>Users</strong> in the top navigation bar.</li>
          <li>Locate the user in the list or search by name or email.</li>
          <li>Click the user's row to open their profile.</li>
          <li>Select the new role in the role dropdown: <strong>Admin</strong> or <strong>User</strong>.</li>
          <li>Click <strong>Save</strong> to apply the change.</li>
        </ol>
        <a href="/hub/how-to/change-role/" class="howto-cta">Full guide →</a>
      </div>
    </div>

## Account Settings

<div class="qs-stepper">
  <div class="qs-tabbar">
    <a class="qs-tab" href="#">Change Password</a>
    <a class="qs-tab" href="#">Change Language</a>
  </div>
  <div class="qs-panels">

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Change Your Password</div>
        <p class="howto-card-desc">Update your own password directly from the Account Settings page.</p>
        <ol class="howto-steps-preview">
          <li>Click your <strong>profile icon</strong> in the top-right corner.</li>
          <li>Select <strong>Account Settings</strong> from the dropdown.</li>
          <li>Click <strong>Change Password</strong>.</li>
          <li>Enter your current password, then the new password twice.</li>
          <li>Click <strong>Save</strong> — the new password applies immediately.</li>
        </ol>
        <a href="/hub/how-to/change-password/" class="howto-cta">Full guide →</a>
      </div>
    </div>

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Change the Interface Language</div>
        <p class="howto-card-desc">Switch Hub between German and English — the setting is stored in the browser.</p>
        <ol class="howto-steps-preview">
          <li>Click your <strong>profile icon</strong> in the top-right corner.</li>
          <li>Select <strong>Account Settings</strong>.</li>
          <li>Locate the <strong>Language</strong> setting.</li>
          <li>Choose <strong>German</strong> or <strong>English</strong>.</li>
          <li>Click <strong>Save</strong> — the UI switches language immediately.</li>
        </ol>
        <a href="/hub/how-to/change-language/" class="howto-cta">Full guide →</a>
      </div>
    </div>
