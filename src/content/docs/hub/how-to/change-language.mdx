title: "Change the Interface Language"
description: "How to switch the Hub interface between English and German."
---

import { Steps } from '@astrojs/starlight/components';

<a href="/hub/how-to" class="guide-back-link">← How-To Guides</a>

Hub is available in English and German. The language selection applies to the current browser session only — it is not tied to your account and will reset on the next login.

<Steps>
1. **Locate the language toggle** — Find the **DE / EN** toggle in the top-right area of the navigation bar.

2. **Click the desired language** — Click **DE** to switch to German or **EN** to switch to English. The interface updates immediately — no page reload is required.
</Steps>
