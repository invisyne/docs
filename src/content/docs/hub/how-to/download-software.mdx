Hub provides download links for all current software releases — both Edge firmware and the Crawler.Companion App.

<Steps>
1. **Go to Software** — Click **Software** in the top navigation bar.

2. **Choose the software type** — The page is divided into two sections:

   | Section | Content |
   |---|---|
   | **Crawler** | Firmware files for Edge devices |
   | **Companion** | Installer for the Crawler.Companion App |

3. **Find the version** — Browse the list and locate the release you need. Releases are sorted by version number, newest first.

4. **Open the detail page** — Click on the version entry to open its detail page. Here you will find release notes and further information about the release.

5. **Download** — In the detail page, click the **Download** button to save the file to your computer.
</Steps>

:::note
Download links are only available for officially released versions. Upcoming or internal versions do not have a download button.
:::
