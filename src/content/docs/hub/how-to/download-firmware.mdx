Hub hosts firmware files for Edge devices as well as installers for Crawler.Companion. Both are available under the Software section.

<Steps>
1. **Go to Software** — Click **Software** in the top navigation bar.

2. **Find the desired version** — Browse the available versions. The **Crawler** section contains Edge firmware; the **Companion** section contains Crawler.Companion installers. Versions are listed newest-first.

3. **Open the detail page** — Click on a version entry to open its detail page with release notes and further information.

4. **Download** — Click the **Download** button to save the file to your browser's default download location. Depending on the release, full versions and patches may both be available for download.
</Steps>
