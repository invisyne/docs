You can add or update a device's metadata at any time from the Devices list.

<Steps>
1. **Go to Devices** — Select **Devices** in the top navigation bar.

2. **Open the device** — Click on the row of the device you want to edit. The device detail panel opens.

3. **Click Edit** — Click the **Edit** button (pencil icon) in the detail panel to enable editing mode.

4. **Fill in the fields** — Add or update any of the following:

   | Field | Description |
   |---|---|
   | **Name** | A recognisable label for the device |
   | **Location** | Where the device is physically installed |
   | **Address** | Street address of the installation site |
   | **Contact** | Responsible person or team for this device |
   | **Order number** | Internal order reference |
   | **Delivery date** | Date the device was delivered |
   | **Notes** | Free-text field for any additional information |

5. **Save your changes** — Click **Save**. The updated information is reflected immediately in the device list.
</Steps>
