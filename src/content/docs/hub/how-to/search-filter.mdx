Use the search bar, column sorting, and filters to quickly locate any device in your fleet.

<Steps>
1. **Open the search bar** — In the top-right corner of the Devices page, click the search bar and type your query. The search matches against serial number, device name, type, location, and firmware version.

2. **Sort by column** — Click any column header (for example, Name or Firmware) to sort the list ascending. Click the same header again to reverse the sort order.

3. **Apply a filter** — Click the filter icon next to the search bar to open the filter panel. Select one or more criteria: device type, location, or firmware version. The list updates immediately to show only matching devices.

4. **Clear filters** — To reset, remove individual filter tags by clicking the × next to each one, or click **Clear all** to remove all active filters at once.
</Steps>
