# Device Management

## Dashboard - Device Overview

The central device overview provides a tabular display of all managed Edge devices with the following information:

- **Serial Number**: Unique device identification
- **Name**: User-defined designation
- **Type**: Device type (e.g., Wago 752-9400, Siemens Simatic IPC127E)
- **Location**: Device location
- **Firmware (Delivery)**: Installed firmware version

## Filter Functions

- **Search Function**: Quick location of specific devices
- **Sorting**: Sortable by various columns
- **Filter**: Filtering by device type, location, or other criteria

## Device-Level Actions

Clicking on a device opens a detailed view with extended information and action options.
