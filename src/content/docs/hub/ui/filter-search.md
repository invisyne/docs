# Search and Filter Functions

## Overview

The Hub offers comprehensive search and filter options for efficient management of large device inventories.

![](https://api.archbee.com/api/optimize/5QJBvgamF9LtImfLB456o/hCcdSikCrHfO0TIt7aRE2_suchfunktion.PNG)

## Search Function

- **Position**: The search field is located in the top right above the device list
- **Real-time Search**: The search filters results in real-time as you type
- **Search Scope**: Searches all columns (Serial Number, Name, Type, Location, Firmware)
- **Example**: Entering "Wago 7" will display only devices with "Wago 752" in the Type field
- **Clear**: X icon in the search field for quickly resetting the search

## Sorting

- **Column Sorting**: Click on column headers to sort the list in ascending or descending order
- **Sort Indicators**: Arrows (↓/↑) show the current sort direction
- **Multi-level Sorting**: Primary and secondary sort criteria possible

## Filter Options

- **Device Type Filter**: Filter by specific device models
- **Location Filter**: Group by installation locations
- **Firmware Filter**: Display devices with specific firmware versions
- **Combined Filters**: Multiple filter criteria can be applied simultaneously

## Device-Level Actions

Clicking on a device opens a detailed view with extended information and action options.
