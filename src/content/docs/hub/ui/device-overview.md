# User Interface - Overview

## Main Navigation

The main navigation is located in the upper area of the application and provides access to the following sections:

- **Devices**: Central device overview
- **Customers**: Customer management (depending on authorization)
- **Users**: User management (admin area)
- **Software**: Software-related functions
- **Hardware**: Hardware configurations

## User Menu

In the upper right area, the user menu contains:

- Language selection (German/English)
- User profile with initials
- Account settings
- Logout function

# Device Detail View

## Crawler Details

The detail view of an individual device shows the following information:

### Basic Information

- **Serial Number**: Unique device ID
- **Name**: Device name
- **Type**: Device type and model
- **Location**: Installation location
- **Firmware (Delivery)**: Current firmware version
- **Order Number**: Internal reference number
- **Delivered on**: Delivery date
- **Note**: Free text field for additional information

### Available Tabs

- **Status**: Current operating status of the device
- **Performance**: Performance metrics and utilization
- **Detail Information**: Extended technical details
- **Error Logs**: Logging of errors and warnings
- **License**: License management and subscription status

## Actions and Setup

The detail view offers the following action options:

### Setup Functions

- **Save/Load HW Configuration**: Save and restore hardware configurations
- **Export Database**: Export device database
- **Perform FW Update**: Firmware update for the device
- **Set Alarms**: Configuration of device alarms

### Edit and Save

- **Cancel**: Discard changes
- **Save**: Apply and save changes
