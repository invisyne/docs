## Accessing the Profile Menu

In the top right corner of the user interface, you'll find the profile icon (displaying the user's initials, e.g., "JG" for Jordan Gränitz). When you click on the profile, a dropdown menu opens.

## Available Options in the Profile Menu

This menu provides the following options:

- **Account Settings**: Access to personal settings (indicated by a gear icon)
- **Logout**: Sign out from the Hub (indicated by an arrow icon)

## Logging Out of the System

To log out, simply click on "Logout" in the opened menu. You will then be signed out of the system and redirected to the login page.
