### Language Selection

## Overview

The Hub is multilingual and supports easy switching between different languages.

## Available Languages

- **Deutsch**: Default language for German users
- **English**: English user interface for international users

![](https://api.archbee.com/api/optimize/5QJBvgamF9LtImfLB456o/4PKCjH15cf_cgZwVaa1T0_sprache.PNG)

## Changing the Language

1. Click on the language icon (🌐) or the language name (e.g., "Deutsch") in the top right corner of the user interface
2. A dropdown menu opens with the available languages
3. Select your desired language
4. The entire user interface switches immediately to the selected language
5. The language setting is automatically saved for future sessions

## Multilingual Elements

The language selection affects all areas of the application:

- All menus and navigation elements
- Forms and input fields
- Error messages and notifications
- Table columns and labels
- Button texts and actions

**Note**: The language setting is user-specific and is saved with your profile.
