## Security Guidelines

### Anchor Link

The security of your data and devices is our highest priority. Please observe the following security guidelines when using the Hub:

## Authentication and Access

### Password Security

- **Use strong passwords:** Use passwords with at least 8 characters, including uppercase and lowercase letters, numbers, and special characters. 
- **Regular password changes:** Change your password at regular intervals (recommended: every 90 days). 
- **No password reuse:** Use a unique password for the Hub that you do not use for other services. 
- **Secure storage:** Never share your password with third parties and do not store it unencrypted. 

### Two-Factor Authentication (2FA)

- **Email verification:** The system sends verification codes to your registered email address. 
- **Code validity:** Verification codes are time-limited and should be entered promptly. 
- **Suspicious activity:** Report unexpected verification requests to the administrator immediately. 

## Account and Access Security

### Secure Session Management

- **Automatic logout:** You will be automatically logged out after a period of inactivity. 
- **Manual logout:** Always log out actively after finishing your work, especially on public or shared computers. 
- **Browser security:** Always use up-to-date browser versions with the latest security updates. 

### Access Control

- **Role-based permissions:** Your access is limited to the functions required for your role. 
- **Do not share credentials:** Never share your login credentials with other users. 
- **Suspicious access attempts:** Inform the administrator of any unauthorized access attempts. 

## Data Security

### Sensitive Data

- **Confidentiality:** Treat all information displayed in the Hub as confidential. 
- **No screenshots:** Do not create screenshots containing sensitive device or customer data. 
- **Secure communication:** Share information from the Hub only through secure, authorized channels. 

## Device and Network Security

### Firmware Updates

- **Authorized updates only:** Perform firmware updates only using verified and authorized versions. 
- **Update logging:** Document all performed updates to ensure traceability. 
- **Critical updates:** Install security-relevant updates promptly. 

## Best Practices

### General Security Measures

- **Up-to-date software:** Keep your operating system and browsers up to date at all times. 
- **Secure networks:** Access the Hub only via trusted, secure networks (avoid public Wi-Fi). 
- **HTTPS connection:** Ensure that the connection to the Hub always uses HTTPS (indicated by the lock icon in the browser’s address bar). 

## In Case of Suspicion

- **Immediate action:** Report security incidents or suspicious activities to the administrator immediately. 
- **Change password:** If compromise is suspected, change your password immediately. 
- **Documentation:** Document the incident with all relevant details (time, type of activity). 

## Compliance and Data Protection

- **GDPR compliance:** The Hub processes personal data in accordance with GDPR regulations. 
- **Data minimization:** Only data necessary for operation is stored. 
- **Retention periods:** Data is stored only as long as required for its intended purpose. 
- **Right of access:** You have the right to request information about your stored data at any time.
