# Software Overview – Functional Scope

The Hub is a web-based management platform that provides the following core functionalities:

## Central Functional Areas

### 1. Device Management

- **Dashboard overview:** Central view of all managed Edge (Crawler) devices 
- **Device detail view:** Comprehensive information on individual devices (status, performance, error logs) 
- **Real-time monitoring:** Monitoring of operational status and performance metrics 
- **Device configuration:** Saving and loading of hardware configurations 

### 2. Firmware and Update Management

- **Single-device updates:** Firmware updates for individual devices 
- **Bulk updates:** Simultaneous firmware updates for multiple devices 
- **Version tracking:** Overview of installed firmware versions 
- **Update logging:** Traceability of performed updates 

### 3. Data Management

- **Database export:** Export of device databases for backup and analysis 
- **Hardware configuration:** Backup and restoration of hardware configurations 
- **Batch export:** Mass export of configurations for multiple devices 

### 4. Alarm and Notification System

- **Status notifications:** Automatic alerts in case of critical events 
- **Error logging:** Detailed recording of errors and warnings 

### 5. License Management

- **Subscription management:** Assignment and management of device licenses 
- **License status:** Overview of active and inactive licenses 

### 6. Search and Filter Functions

- **Real-time search:** Fast device lookup across all data fields 
- **Advanced filters:** Filtering by type, location, firmware, and additional criteria 
- **Sorting:** Flexible sorting by all column attributes 
- **Combined filters:** Simultaneous application of multiple filter criteria 

### 7. Multi-Language Support

- **Multilingual support:** Support for German and English 
- **Dynamic language switching:** Instant switching of the user interface language 
- **User-specific settings:** Individual language preferences per user 

### 8. Security Features

- **Email verification:** Two-factor authentication via email code 
- **Secure login:** Password-protected user accounts 
- **Role-based access control:** Differentiated permission levels 
- **Session management:** Secure session handling with logout functionality 

### 9. Account Settings

- **Profile management:** Editing of personal data (name, email) 
- **Password management:** Secure password change with confirmation 
- **Settings persistence:** Persistent storage of user preferences 

## Admin Responsibilities

### 1. Customer and User Management

- **Customer management:** Creation, editing, and administration of customer accounts 
- **User management:** Creation and management of user accounts 
- **Roles and permissions:** Differentiated access control (Super Admin, Admin, User) 
- **Customer grouping:** Organization of Edge (Crawler) devices by customer 

### 2. License Management

- **Subscription management:** Assignment and management of device licenses 
- **License status:** Overview of active and inactive licenses
