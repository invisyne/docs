  <div class="page-hero-text">
    <p class="page-hero-lead">Edge (Crawler) is a compact industrial edge computing device that captures, evaluates, visualizes, and forwards machine data in real time — directly at the source, without relying on a central server.</p>
  </div>
</div>

<div class="page-hero-body">
  <p>It combines control technology, gateway functionality, and a browser-based interface in a single unit, and works in both connected and air-gapped environments.</p>
  <p>Edge (Crawler) comes with pre-installed connectivity for SIEMENS controllers and Modbus devices, and can be extended with additional functions such as condition monitoring or cloud connectivity.</p>
  <p>Configuration and management is handled via the built-in web interface — accessible directly in the local network without additional software.</p>
</div>
