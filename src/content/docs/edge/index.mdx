## Functional Scope

<div class="feature-grid">
  <div class="feature-card">
    <div class="feature-card-title">Machine Data Capture</div>
    <p>Records data from connected machines and controllers in real time — continuously and without interruption.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Real-time Evaluation</div>
    <p>Processes and visualizes captured data directly on the device, without requiring an external server.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Connectivity</div>
    <p>Pre-installed drivers for SIEMENS controllers, Modbus devices, and OPC UA. Additional protocols can be added as needed.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Browser-based Interface</div>
    <p>All configuration and monitoring is done via the built-in web interface — no additional software required.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Condition Monitoring</div>
    <p>Optional extension for monitoring machine health and detecting anomalies based on continuously recorded data.</p>
  </div>
  <div class="feature-card">
    <div class="feature-card-title">Extensible App Concept</div>
    <p>Extend the device with additional apps for specific use cases — including condition monitoring, load management, cloud connectivity, and more.</p>
  </div>
</div>

## Safety Notes

<div class="security-grid">
  <div class="security-item">
    <div class="security-item-title">Network Changes</div>
    <p>Incorrect network settings can make the device unreachable. Only edit these if you are familiar with IP addresses and subnet masks.</p>
  </div>
  <div class="security-item">
    <div class="security-item-title">Firmware Updates</div>
    <p>Ensure stable power supply to the Edge device before and during a firmware update.</p>
  </div>
  <div class="security-item">
    <div class="security-item-title">Access Control</div>
    <p>The web interface should only be accessible within the intended network. Restrict access where possible.</p>
  </div>
</div>
