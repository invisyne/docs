Field devices are the industrial controllers, sensors, and gateways from which the Edge reads process data. Before a device's variables can be configured for recording, the device must be added to the Edge and a successful connection must be established. The Edge supports three connection protocols: **Modbus TCP**, **OPC UA**, and **Siemens SIMATIC (S7)** — select the tab for the relevant protocol below.

In the main menu, navigate to **Data Recording** and click **+ Add devices**.

Enter the connection details:

- **Address** — IP address of the Modbus device
- **Device name** — used to identify the device within the Edge
- **Port** — default is 502
- **Modbus RTU** — enable if the field device uses the Modbus RTU protocol. Modbus RTU is the older Modbus variant and uses a master/slave architecture — the Edge acts as the Modbus Master and polls the connected field devices (slaves). When enabled, an additional **Slave ID** field appears to identify the target device on the bus.

Disable **Symbolic addressing**. The fields **Slot number** and **Rack number** appear. Absolute addressing is used for **S7-300 and S7-400** controllers, which do not support symbolic addressing. It can also be used with S7-1200 and S7-1500 if symbolic addressing is not required.

:::note
Secured connections (access protection) are not supported for S7-300/400 controllers.
:::

Enter the connection details:

- **Address** — IP address of the SIMATIC controller
- **Device name** — used to identify the device within the Edge
- **Symbolic addressing** — disabled
- **Slot number** — specifies the position of the CPU or communication processor within the rack. Typically **2** for S7-300/400. Found in the hardware configuration in TIA Portal or SIMATIC Manager.
- **Rack number** — specifies the rack in which the CPU is installed. In **95% of cases this is 0** — the main rack where the CPU is located. In redundant CPU configurations, use the rack number of the currently active CPU.

**Finding slot and rack number**

The slot and rack number can be found in the hardware configuration of the project. Open the hardware configuration in **TIA Portal** (or **SIMATIC Manager** for S7-300/400 projects) and locate the CPU in the rack view.

**Enabling PUT/GET communication (S7-1200 / S7-1500 only)**

When using absolute addressing with an S7-1200 or S7-1500, PUT/GET communication must be enabled in TIA Portal. Open the PLC properties and navigate to **Protection &amp; Security → Connection mechanisms**. Enable **Permit access with PUT/GET communication from remote partner**.

<div class="screenshot-frame">
  <img src={tiaPutGetImg.src} alt="TIA Portal — enabling PUT/GET communication access" />
</div>

**Disabling optimized block access**

For absolute addressing, the data block must have **Optimized block access** disabled. Open the data block properties in TIA Portal, go to **Attributes**, and uncheck **Optimized block access**.

<div class="screenshot-frame">
  <img src={tiaDbNoOptimizedImg.src} alt="TIA Portal — data block attributes with optimized block access disabled" />
</div>

With optimized access disabled, each variable gets a fixed byte offset visible in the data block view, which is used as the address in the Edge (e.g. `DB10.DBX0.0`).

**OPC UA — Configuring username/password authentication in TIA Portal**

If the OPC UA server in TIA Portal requires authentication, the following must be configured on the controller side:

1. In TIA Portal, open the PLC and navigate to **Properties → OPC UA → Server**.
2. Enable the **OPC UA server** if it is not already active.
3. Under **Security**, enable a security policy — at minimum **Basic256Sha256** with mode **Sign & Encrypt** is recommended.
4. Under **Authentication**, enable the **Username and password** option.
5. Add a user: under **User management**, create a new entry with a username and password. These credentials are entered in the Edge **Secured device connection** fields.
6. Compile and download the updated PLC configuration.

:::note
The exact menu structure may vary slightly depending on the TIA Portal version. If you have questions about OPC UA configuration in TIA Portal, contact your Siemens representative or reach out to us.
:::

**Configuring access protection in TIA Portal — SIMATIC Symbolic (S7-1200 / S7-1500)**

For SIMATIC controllers using symbolic addressing, access protection is managed through the access level settings in TIA Portal. The Edge authenticates using the password assigned to the configured access level.

1. In TIA Portal, open the PLC and navigate to **Properties → Protection &amp; Security → Access level**.
2. Select the protection level — **Read access** permits read-only access and is sufficient for the Edge to retrieve data. **HMI access** grants slightly broader permissions and can also be used.
3. Enter a password for the selected access level. This is the password that will be entered in the Edge **Secured device connection** field.
4. Compile and download the updated PLC configuration.

:::note
If the PLC is set to **Full access (no protection)**, no password is required and the secured connection toggle does not need to be enabled.
:::

This error means the device has access protection enabled, but **Secured device connection** was not activated when the device was added.
