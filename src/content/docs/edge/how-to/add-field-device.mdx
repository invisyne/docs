**Symbolic addressing — enabling PUT/GET access**

In TIA Portal, open the PLC properties and navigate to **Protection &amp; Security → Connection mechanisms**. Enable **Permit access with PUT/GET communication from remote partner**.

<div class="screenshot-frame">
  <img src={tiaPutGetImg.src} alt="TIA Portal — enabling PUT/GET communication access" />
</div>

With symbolic addressing enabled, variable names and data block structures are read directly from the PLC. The data block variables and their types are visible in TIA Portal under the program blocks.

<div class="screenshot-frame">
  <img src={tiaDatablockImg.src} alt="TIA Portal — data block with variable structure" />
</div>

**Absolute addressing — disabling optimized block access**

For absolute addressing (S7-300/400 or S7-1200/1500 without symbolic addressing), the data block must have **Optimized block access** disabled. Open the data block properties in TIA Portal, go to **Attributes**, and uncheck **Optimized block access**.

<div class="screenshot-frame">
  <img src={tiaDbNoOptimizedImg.src} alt="TIA Portal — data block attributes with optimized block access disabled" />
</div>

With optimized access disabled, each variable gets a fixed byte offset visible in the data block view, which is used as the address in the Edge (e.g. `DB10.DBX0.0`).

<div class="screenshot-frame">
  <img src={tiaDbAddressesImg.src} alt="TIA Portal — data block with absolute addresses (byte offsets)" />
</div>

**Configuring access protection in TIA Portal (Siemens SIMATIC)**

Access protection must be configured on the PLC side before a secured connection can be established from the Edge.

**S7-1200 / S7-1500:**

1. Open the PLC in TIA Portal and go to **Properties → Protection &amp; Security → Access level**.
2. Set the access level to **Read access** or **HMI access** (or higher restriction).
3. Enter a password for the selected access level.
4. Compile and download the configuration to the PLC.

The password entered in Edge must match the password set for the **read** or **HMI** access level in TIA Portal.

:::note
For the Edge SIMATIC connector to read data, at minimum **Read access** must be permitted. If the PLC is set to **Full access (no protection)**, no password is required and the secured connection toggle does not need to be enabled.
:::

**S7-300 / S7-400:**

1. Open the CPU properties in TIA Portal (or STEP 7) and go to **Properties → Protection**.
2. Select a protection level and set the corresponding password.
3. Download the updated configuration to the PLC.

**If the connection fails with "only secured connection"**

This error appears when the secured connection option was not configured during device creation. To fix it afterwards, follow the steps below.

This error means the device has access protection enabled, but **Secured device connection** was not activated when the device was added.

  <img src={connectionErrorImg.src} alt="Device connection widget showing 'only secured connection' error" />
</div>
