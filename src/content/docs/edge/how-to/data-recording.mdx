**Import from device (S7 symbolic addressing only)**

:::note
Importing measured variables directly from the field device is currently only supported for S7 controllers with symbolic addressing.
:::

:::note
For large PLC structures, the import may fail. Use the CSV import as an alternative.
:::

Before importing, a connection to the field device must be established. The connection status is shown in the **Device connection** widget on the device page.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={deviceConnectedImg.src} alt="Device connection status" />
</div>

On the device page, the **Measured variables** widget shows the total number of configured variables and how many are currently being recorded. Click **Import** to add variables from the field device or from a CSV file.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={measuredVariablesImg.src} alt="Measured variables widget" />
</div>

<div class="screenshot-frame">
  <img src={importSourceImg.src} alt="Import source dialog" />
</div>

Clicking **From device** retrieves the structure and measured variables directly from the field device. The Variable Browser then displays all available variables:

- Variables already imported are highlighted in grey
- Variables configured on the Edge but not found on the field device during import are highlighted in yellow

Select all desired measured variables, then open the **Cart** and click **Import all**.

  <img src={importCartImg.src} alt="Import cart" />
</div>

**Editing or deleting a single variable**

Variables can be edited inline directly in the Variable Browser (name and sampling rate). For all other settings, open the edit dialog via the icon next to the variable.

<div class="screenshot-frame screenshot-frame-xs">
  <img src={variableEditIconImg.src} alt="Variable edit icon" />
</div>

<div class="screenshot-frame">
  <img src={variableEditDialogImg.src} alt="Variable edit dialog" />
</div>

:::note
Deleting a measured variable removes it from the visualization. Existing panels may display incorrect or no data. Recorded data is not deleted — used disk space is not freed.
:::

**Bulk editing or deleting**

To edit or delete multiple variables at once, select them in the Variable Browser by adding them to the cart. Selected variables are highlighted in color; the number of selected items is shown on the cart icon. Open the cart to review and adjust the selection. Removing a variable from the cart does not delete it.

<div class="screenshot-frame">
  <img src={cartSelectionImg.src} alt="Cart selection list" />
</div>

Click **Edit all** to open the bulk edit dialog. Individual settings can be overwritten for all selected variables at once.

<div class="screenshot-frame">
  <img src={bulkEditDialogImg.src} alt="Bulk edit dialog" />
</div>

If the current values differ across the selection, this is indicated.

<div class="screenshot-frame">
  <img src={bulkEditMixedImg.src} alt="Bulk edit with mixed values" />
</div>

After applying changes, the cart remains open for further edits or can be closed.
