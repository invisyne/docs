Before configuring data recording, the following information about the field device should be available:

- IP address of the field device
- Device type (e.g. Modbus, Simatic S7)

The field device must be connected to the Edge network and added in the Edge UI before proceeding. See [Adding a Field Device](/edge/how-to/add-field-device) for step-by-step instructions.

**Import from device (S7 symbolic addressing only)**

:::note
Importing measured variables directly from the field device is currently only supported for S7 controllers with symbolic addressing.
:::

:::note
For large PLC structures, the import may fail. Use the CSV import as an alternative.
:::

Before importing, a connection to the field device must be established. The connection status is shown in the **Device connection** widget on the device page.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={deviceConnectedImg.src} alt="Device connection status" />
</div>

On the device page, the **Measured variables** widget shows the total number of configured variables and how many are currently being recorded. Click **Import** to add variables from the field device or from a CSV file.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={measuredVariablesImg.src} alt="Measured variables widget" />
</div>

<div class="screenshot-frame">
  <img src={importSourceImg.src} alt="Import source dialog" />
</div>

Clicking **From CSV file** allows importing variables from a CSV file — use this if the device import is not supported or fails for large PLC structures.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={importCsvImg.src} alt="CSV import option" />
</div>

Clicking **From device** retrieves the structure and measured variables directly from the field device. The Variable Browser then displays all available variables:

- Variables already imported are highlighted in grey
- Variables configured on the Edge but not found on the field device during import are highlighted in yellow

Select all desired measured variables, then open the **Cart** and click **Import all**.

<div class="screenshot-frame">
  <img src={importCartImg.src} alt="Import cart" />
</div>

Before confirming, set the desired configuration for the imported variables.

<div class="screenshot-frame">
  <img src={importConfigImg.src} alt="Import configuration" />
</div>

**Editing or deleting a single variable**

Variables can be edited inline directly in the Variable Browser (name and sampling rate). For all other settings, open the edit dialog via the icon next to the variable.

<div class="screenshot-frame screenshot-frame-xs">
  <img src={variableEditIconImg.src} alt="Variable edit icon" />
</div>

<div class="screenshot-frame">
  <img src={variableEditDialogImg.src} alt="Variable edit dialog" />
</div>

:::note
Deleting a measured variable removes it from the visualization. Existing panels may display incorrect or no data. Recorded data is not deleted — used disk space is not freed.
:::

**Bulk editing or deleting**

To edit or delete multiple variables at once, select them in the Variable Browser by adding them to the cart. Selected variables are highlighted in color; the number of selected items is shown on the cart icon. Open the cart to review and adjust the selection. Removing a variable from the cart does not delete it.

<div class="screenshot-frame">
  <img src={cartSelectionImg.src} alt="Cart selection list" />
</div>

Click **Edit all** to open the bulk edit dialog. Individual settings can be overwritten for all selected variables at once.

<div class="screenshot-frame">
  <img src={bulkEditDialogImg.src} alt="Bulk edit dialog" />
</div>

If the current values differ across the selection, this is indicated.

<div class="screenshot-frame">
  <img src={bulkEditMixedImg.src} alt="Bulk edit with mixed values" />
</div>

After applying changes, the cart remains open for further edits or can be closed.

**Manually creating a variable**

Variables can also be created manually without an import. Click **+ Add variable** on the variable browser to open the creation dialog. Enter the variable name, address, data type, and sampling interval.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={variableCreateImg.src} alt="Create measured variable dialog" />
</div>

The address format depends on the device type:

<div class="screenshot-frame">
  <img src={variableAddressFormatsImg.src} alt="Address format reference — S7 symbolic, S7 absolute, Modbus TCP" />
</div>

A correctly configured variable appears in the list with its type, address, sampling interval, and last recorded value.

<div class="screenshot-frame">
  <img src={variableConnectedImg.src} alt="Variable list showing a connected and recording variable" />

The Performance Analysis tool tests whether the Edge is sampling variables at the configured rate. It checks that no values are missed or delayed — useful after setup or when adjusting sampling intervals.

:::note
Recording for the tested device is interrupted while a test is running. Do not run performance tests on a device that is actively recording production data.
:::

Open the device page and click **Performance Analysis** to open the analysis overview. The last test result is shown alongside the available test types.

<div class="screenshot-frame">
  <img src={perfOverviewImg.src} alt="Performance Analysis overview — test selection and last results" />
</div>

Click **Run test** under **Setpoint-Actual Comparison** to open the configuration dialog. Select a test duration using the slider (10 seconds to 30 minutes) and click **Start**.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={perfStartImg.src} alt="Setpoint-Actual Comparison start dialog with duration slider" />
</div>

A warning is shown before the test starts confirming that recording will be interrupted.

<div class="screenshot-frame screenshot-frame-sm">
  <img src={perfWarningImg.src} alt="Warning: recording will be interrupted during the test" />
</div>

The test runs in the background and shows a progress indicator. Do not switch off the Edge or the data source while the test is running.

<div class="screenshot-frame">
  <img src={perfRunningImg.src} alt="Performance Analysis — test running with progress indicator" />
</div>

After completion, the results page shows a quality rating (color scale from red to green), the number of failed test runs, and key statistics including average, median, minimum, and maximum sampling rate.

<div class="screenshot-frame">
  <img src={perfResultsImg.src} alt="Performance Analysis results — quality rating and sampling rate statistics" />
</div>
