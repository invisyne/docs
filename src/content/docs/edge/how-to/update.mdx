Updates are installed on the Edge by uploading an update bundle — a `.zip` file provided by Invisyne that contains the new firmware and service versions. There is no automatic update mechanism; each update must be uploaded manually.

<Steps>

1. **Navigate to the Update page**

   In the left sidebar, go to **System → Einstellungen**. On the settings overview, click the **Update** tile.

   <div class="screenshot-frame">
     <img src={settingsMenuImg.src} alt="Settings menu overview" />
   </div>

2. **Check the current version**

   The Update overview shows the currently installed version and a summary of all installed components. If no update bundle has been uploaded yet, the status reads **Kein verfügbares Update**.

   <div class="screenshot-frame">
     <img src={updateOverviewImg.src} alt="Update overview" />
   </div>

3. **Upload the update bundle**

   Click **Bundle Hochladen**. In the dialog that appears, click **Bundle auswählen** and select the `.zip` update file provided by Invisyne. Then click **Hochladen** to begin the upload.

   <div class="screenshot-frame screenshot-frame-sm">
     <img src={bundleDialogImg.src} alt="Bundle upload dialog" />
   </div>

4. **Install the update**

   Once the bundle has been uploaded, the available update is displayed on the overview page. Review the update notes and the list of components to be updated, then confirm the installation.

   :::note
   The Edge will restart automatically during the update process. This may take several minutes. Do not disconnect the device from the power supply during this time.
   :::

5. **Verify the update**

   After the restart, the Update overview shows the newly installed version under **Letztes erfolgreiches Update**, along with the date and the list of updated components.

</Steps>
