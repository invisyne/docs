Crawler.Companion erfordert keine klassische Installation. Die `.exe`-Datei wird direkt aus dem Hub heruntergeladen und ausgeführt.

<Steps>

1. **Hub-Login → Software**

   Melde dich unter [hub.invisyne.com](https://hub.invisyne.com) an und navigiere zum Bereich **Software**. Suche die gewünschte Companion-Version und klicke auf **Downloads und Details**.

   <div class="screenshot-frame">
     <img src={downloadPageImg.src} alt="Hub Software-Seite mit Companion-Version" />
   </div>

2. **Datei herunterladen**

   Klicke auf der Versionsdetailseite rechts auf den **Download**-Button. Ein ZIP-Archiv (z. B. `crawler.companion-v1.2.0.zip`) wird auf deinen Computer gespeichert.

   <div class="screenshot-frame">
     <img src={downloadButtonImg.src} alt="Download-Button auf der Versionsdetailseite" />
   </div>

3. **Entpacken und starten**

   Entpacke das ZIP-Archiv und doppelklicke die `.exe`-Datei darin.

   <div class="screenshot-frame">
     <img src={exeImg.src} alt="Entpackte Companion-exe-Datei" />
   </div>

4. **Unter Windows: Sicherheitshinweis bestätigen**

   Windows SmartScreen kann den Start blockieren. Klicke auf **Weitere Informationen**.

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src={warningImg.src} alt="Windows SmartScreen Warnung" />
   </div>

   Klicke anschließend auf **Trotzdem ausführen**.

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src={warningExpandedImg.src} alt="Windows SmartScreen ausgeklappt mit Trotzdem ausführen" />
   </div>

5. **Companion startet**

   Crawler.Companion ist jetzt geöffnet.

</Steps>
