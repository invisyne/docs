---
title: "Installation"
description: "Crawler.Companion aus dem Hub herunterladen und unter Windows starten."
---

import { Steps } from '@astrojs/starlight/components';

Crawler.Companion erfordert keine klassische Installation. Die `.exe`-Datei wird direkt aus dem Hub heruntergeladen und ausgeführt.

<Steps>

1. **Hub öffnen → Software**

   Navigiere im Hub zum Bereich **Software** und suche die gewünschte Companion-Version. Klicke auf **Downloads und Details**.

   <div class="screenshot-frame">
     <img src="/images/companion/companion_download.png" alt="Hub Software-Seite mit Companion-Version" />
   </div>

2. **Datei herunterladen**

   Klicke auf der Versionsdetailseite rechts auf den **Download**-Button. Ein ZIP-Archiv (z. B. `crawler.companion-v1.2.0.zip`) wird auf deinen Computer gespeichert.

   <div class="screenshot-frame">
     <img src="/images/companion/companion_download_button.png" alt="Download-Button auf der Versionsdetailseite" />
   </div>

3. **Entpacken und starten**

   Entpacke das ZIP-Archiv und doppelklicke die `.exe`-Datei darin.

   <div class="screenshot-frame">
     <img src="/images/companion/companion_exe.png" alt="Entpackte Companion-exe-Datei" />
   </div>

4. **Unter Windows: Sicherheitshinweis bestätigen**

   Windows SmartScreen kann den Start blockieren. Klicke auf **Weitere Informationen**.

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src="/images/companion/companion_windows_warning.png" alt="Windows SmartScreen Warnung" />
   </div>

   Klicke anschließend auf **Trotzdem ausführen**.

   <div class="screenshot-frame" style="max-width: 500px;">
     <img src="/images/companion/companion_windows_warning_expanded.png" alt="Windows SmartScreen ausgeklappt mit Trotzdem ausführen" />
   </div>

5. **Companion startet**

   Crawler.Companion ist jetzt geöffnet.

</Steps>
