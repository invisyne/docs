import { Steps } from '@astrojs/starlight/components';

Crawler.Companion bietet zwei Wege, Messdaten von einem Edge-Gerät abzurufen — ohne Browser und ohne direkten Zugang zur Web-Oberfläche des Geräts.

<div class="ht-glossary">
  <div class="ht-glossary-item open">
    <button class="ht-glossary-trigger" aria-expanded="true">Warum Daten exportieren?</button>
    <div class="ht-glossary-body">
      <p>Edge-Geräte zeichnen Messdaten kontinuierlich auf. Der Export ermöglicht es, diese Daten abzurufen — entweder als CSV-Datei zur lokalen Weiterverarbeitung oder direkt in Deepview zur visuellen Analyse.</p>
    </div>
  </div>
  <div class="ht-glossary-item">
    <button class="ht-glossary-trigger" aria-expanded="false">Was sind Runs?</button>
    <div class="ht-glossary-body">
      <p>Ein Run ist eine definierte Messaufzeichnung, die auf dem Gerät gespeichert wird — mit einem klar definierten Start- und Endzeitpunkt. Runs werden automatisch erstellt, wenn das Gerät eine Aufzeichnung startet und beendet. Der Export nach Runs ermöglicht es, gezielt einzelne Messsitzungen auszuwählen, anstatt nach einem Zeitraum zu filtern.</p>
    </div>
  </div>
  <div class="ht-glossary-item">
    <button class="ht-glossary-trigger" aria-expanded="false">Was ist Deepview?</button>
    <div class="ht-glossary-body">
      <p>Deepview ist ein browserbasiertes Analysetool, das Signaldaten als interaktive Diagramme visualisiert. Es ist mit dem Hub-Account verknüpft und ermöglicht die detaillierte Auswertung und den Vergleich von Messungen. Beim Export zu Deepview überträgt Companion die Daten direkt — die Ergebnisse öffnen sich im Browser, keine zusätzliche Software notwendig.</p>
    </div>
  </div>
</div>

<div class="ht-note-block">
  <p>Die Deepview-Option ist nur verfügbar, wenn der Hub-Account Deepview-Zugriff hat. Wenn sie ausgegraut ist, bitte den Administrator kontaktieren.</p>
</div>

Beide Methoden unterstützen zwei Exportformate — wählen, was zum Workflow passt:

<p class="ht-format-text"><strong>CSV</strong> — Datei auf dem PC &nbsp;·&nbsp; <strong>Deepview</strong> — öffnet direkt im Browser, keine zusätzliche Software notwendig</p>

  <div class="qs-tabbar ht-card-tabbar">
    <a class="qs-tab ht-method-card" href="#">
      <span class="ht-method-card-label">Methode 1</span>
      <span class="ht-method-card-title">Zeitraumbasierter Export</span>
      <span class="ht-method-card-desc">Alle Signaldaten innerhalb eines definierten Start- und Endzeitpunkts exportieren.</span>
    </a>
    <a class="qs-tab ht-method-card" href="#">
      <span class="ht-method-card-label">Methode 2</span>
      <span class="ht-method-card-title">Runbasierter Export</span>
      <span class="ht-method-card-desc">Gezielt einzelne abgeschlossene Messaufzeichnungen auswählen und exportieren.</span>
    </a>
  </div>

  <div class="qs-panels">

    <div class="qs-panel">

      <p>Diese Methode verwenden, wenn alle Signaldaten innerhalb eines bestimmten Start- und Endzeitpunkts exportiert werden sollen — unabhängig von einzelnen Runs.</p>

      <div class="ht-phase-steps">

        <div class="ht-phase-label">Gerät vorbereiten</div>

        <Steps>

        1. **Gerät auswählen**

           In der Geräteliste auf das gewünschte Gerät klicken.

        2. **Tab „Export" öffnen**

           Im Detailpanel auf den Tab **Export** klicken.

        </Steps>

        <div class="ht-phase-cont-2">

          <div class="ht-phase-label">Export konfigurieren</div>

          <Steps>

          1. **„Zeitraum" auswählen**

             Sicherstellen, dass der Tab **Zeitraum** in den Export-Einstellungen aktiv ist.

          2. **Zeitraum festlegen**

             **Von**- und **Bis**-Datum mit Uhrzeit eingeben.

          3. **Exportformat wählen**

             Unter **Export Format** entweder **CSV** oder **Deepview** auswählen. Bei CSV erscheint ein **Speicherpfad**-Feld mit dem Standardspeicherort. Auf das Stift-Symbol klicken, um einen anderen Ordner auszuwählen.

             <div class="screenshot-frame" style="max-width: 680px">
               <img src="/images/companion/exporter-deepview-link-zoom.jpg" alt="In Deepview öffnen Button nach dem Export" />
             </div>

          </Steps>

        </div>

        <div class="ht-phase-cont-5">

          <div class="ht-phase-label">Starten</div>

          <Steps>

          1. **Export starten**

             Auf **Exportieren** klicken.

          2. **Deepview öffnen** *(nur bei Deepview)*

             Nach Abschluss des Exports erscheint der Button **In Deepview öffnen** — darauf klicken. Deepview öffnet sich im Browser mit den exportierten Daten.

          </Steps>

        </div>

      </div>

    </div>

    <div class="qs-panel">

      <p>Diese Methode verwenden, wenn gezielt eine oder mehrere Messsitzungen exportiert werden sollen. Jeder ausgewählte Run wird separat exportiert — ideal zum Vergleich einzelner Aufzeichnungen oder zum Teilen einer bestimmten Messsitzung.</p>

      <div class="ht-phase-steps">

        <div class="ht-phase-label">Gerät vorbereiten</div>

        <Steps>

        1. **Gerät auswählen**

           In der Geräteliste auf das gewünschte Gerät klicken.

        2. **Tab „Export" öffnen**

           Im Detailpanel auf den Tab **Export** klicken.

        </Steps>

        <div class="ht-phase-cont-2">

          <div class="ht-phase-label">Export konfigurieren</div>

          <Steps>

          1. **„Runs" auswählen**

             In den Export-Einstellungen auf den Tab **Runs** klicken. Die Liste zeigt alle abgeschlossenen Runs mit Start- und Endzeitpunkt sowie Dauer.

          2. **Einen oder mehrere Runs markieren**

             Die gewünschten Runs aus der Liste auswählen.

          3. **Exportformat wählen**

             Unter **Export Format** entweder **CSV** oder **Deepview** auswählen. Bei CSV erscheint ein **Speicherpfad**-Feld mit dem Standardspeicherort. Auf das Stift-Symbol klicken, um einen anderen Ordner auszuwählen. Bei CSV wird jeder ausgewählte Run als separate Datei gespeichert.

             <div class="screenshot-frame">
               <img src="/images/companion/companion-export-runs.png" alt="Companion Runs-Export mit Run-Auswahl" />
             </div>

          </Steps>

        </div>

        <div class="ht-phase-cont-5">

          <div class="ht-phase-label">Starten</div>

          <Steps>

          1. **Export starten**

             Auf **Exportieren** klicken.

          2. **Deepview öffnen** *(nur bei Deepview)*

             Nach Abschluss des Exports erscheint der Button **In Deepview öffnen** — darauf klicken. Deepview öffnet sich im Browser mit den exportierten Daten.

          </Steps>

        </div>

      </div>

    </div>

  </div>

</div>
