Der Tab **Update** im Geräte-Detailpanel zeigt die installierte Firmware-Version und ermöglicht das Einspielen einer neuen Firmware-Datei.

:::note
Um beispielsweise ein Firmware-Update durchzuführen, ist eine vorherige Anmeldung erforderlich — mehr dazu unter [Login am Edge-Gerät](/de/companion/ui/login-logout-edge).
:::

</div>

  <thead><tr><th>Feld</th><th>Beschreibung</th></tr></thead>
  <tbody>
    <tr><td><strong>Dein System</strong></td><td>Zeigt die installierte Firmware-Version und das Datum des letzten Updates.</td></tr>
    <tr><td><strong>System aktualisieren</strong></td><td>Drop-Zone für die Firmware-Datei (<code>.zip</code>). Datei hineinziehen oder auf <strong>öffnen Sie eine Datei</strong> klicken, um einen Datei-Dialog zu öffnen.</td></tr>
    <tr><td><strong>Update starten</strong></td><td>Startet den Upload und Flash-Vorgang. Ein Fortschrittsbalken zeigt den Übertragungsstatus an.</td></tr>
  </tbody>
</table>
