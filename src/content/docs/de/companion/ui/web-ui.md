## **Zugriff auf die WebUI**

- **Direkter Zugriff auf die Konfiguration:** Der Crawler.Companion bietet eine Schaltfläche (z. B. ein Globus- oder Browser-Symbol), über die der Anwender die WebUI (Web User Interface) des ausgewählten Edge (Crawler)-Geräts direkt aus der Anwendung heraus aufrufen kann.
- **Schnelle Verbindung:** Dies erspart die manuelle Eingabe der IP-Adresse im Browser und ermöglicht einen schnellen Wechsel zur detaillierten, browserbasierten Verwaltung des Geräts.
