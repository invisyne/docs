import exportImg from '../../../../../assets/images/companion/companion-export-panel.png';

Der Tab **Export** ermöglicht den Export von Messdaten eines Edge-Geräts — entweder als CSV-Datei oder direkt nach Deepview. Gerät in der Liste auswählen und im Detailpanel auf den Tab **Export** klicken.

</div>

          <tr><td><strong>Export Format</strong></td><td>Auswahl zwischen <strong>CSV</strong> (wird als Datei gespeichert) oder <strong>Deepview</strong> (öffnet direkt im Browser).</td></tr>
          <tr><td><strong>Speicherpfad</strong></td><td>Speicherort für CSV-Exporte. Über das Stift-Symbol kann ein anderer Ordner gewählt werden.</td></tr>

:::note
Die Deepview-Option ist nur verfügbar, wenn das Hub-Konto Zugang zu Deepview hat. Ist die Option ausgegraut, bitte den Administrator kontaktieren.
:::

Eine Schritt-für-Schritt-Anleitung findet sich unter [Daten exportieren](/de/companion/how-to/export-data).
