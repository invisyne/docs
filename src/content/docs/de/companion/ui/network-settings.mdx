Der Tab **Netzwerk Einstellungen** im Detailpanel ermöglicht die Konfiguration der Netzwerkverbindung eines Edge-Geräts.

<div class="screenshot-frame">
  <img src="/images/companion/geraete-netzwerkeinstellung.png" alt="Crawler.Companion — Tab Netzwerk Einstellungen" />
</div>

<div class="qs-stepper">

  <div class="qs-tabbar">
    <a class="qs-tab" href="#">DHCP</a>
    <a class="qs-tab" href="#">Statische IP</a>
  </div>

  <div class="qs-panels">

    <div class="qs-panel">

      | Feld | Beschreibung |
      |------|--------------|
      | **Als primären Adapter verwenden** | Bestimmt, über welchen Port Companion auf das Gerät antwortet. |
      | **Konfigurationsmodus** | Eingestellt auf DHCP — das Gerät erhält seine IP-Adresse automatisch vom Netzwerk. |
      | **DNS-Server** | Optional. Wird für die Namensauflösung verwendet. |
      | **Speichern** | Übernimmt die Einstellungen. |

    </div>

    <div class="qs-panel">

      | Feld | Beschreibung |
      |------|--------------|
      | **Als primären Adapter verwenden** | Bestimmt, über welchen Port Companion auf das Gerät antwortet. |
      | **Konfigurationsmodus** | Eingestellt auf Statische IP — feste Adresse manuell eingeben. |
      | **IP-Adresse** | Eindeutige Netzwerkadresse des Geräts. |
      | **Subnetzmaske** | Bestimmt den Adressbereich des lokalen Netzwerks. |
      | **Gateway** | Router-Adresse für die Kommunikation außerhalb des lokalen Netzwerks. |
      | **DNS-Server** | Optional. Wird für die Namensauflösung verwendet. |
      | **Speichern** | Übernimmt die Einstellungen. |

    </div>

  </div>

</div>

Eine Schritt-für-Schritt-Anleitung zur Netzwerkkonfiguration findet sich unter [Ersteinrichtung](/de/companion/how-to/initial-setup).
