Der Tab **Netzwerkeinstellungen** im Detailpanel ermöglicht die Konfiguration der Netzwerkverbindung eines Edge-Geräts.

:::note
Um beispielsweise diese Einstellungen zu ändern, ist eine vorherige Anmeldung erforderlich — mehr dazu unter [Login am Edge-Gerät](/de/companion/ui/login-logout-edge).
:::
