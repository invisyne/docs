## **Gerätedetails anzeigen und bearbeiten**

Nach dem Klick auf ein Gerät öffnet sich der Reiter „Details":

| Feld          | Bedeutung                                                          |
| ------------- | ------------------------------------------------------------------ |
| Name          | Name des Geräts                                                    |
| Status        | Status                                                             |
| WebUI         | Link zur Web-Oberfläche des Edges                               |
| Firmware      | Aktuell installierte Version (z. B. ≤2.18) und letztes Update.    |
| MAC 1/2       | Ausgelesene Adressen (X1 / X2).                                    |
| Seriennummer  | Wird ausgelesen, sofern verfügbar.                                 |

- **Technische Details prüfen:** Nach Auswahl eines Geräts kann der Anwender alle relevanten technischen Daten einsehen, die über die Standardübersicht hinausgehen. Dazu können interne Seriennummern, der Hardware-Typ oder spezifische Konfigurations-IDs gehören.
- **Gerätename bearbeiten (Option):** In dieser Ansicht hat der Anwender die Möglichkeit, den Gerätenamen im Netzwerk zu ändern, um die Identifikation zu vereinfachen. Der neue Name wird eingegeben und die Änderung gespeichert.
