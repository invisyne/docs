Der **Backup**-Tab im Geräte-Detailpanel enthält zwei Bereiche: **Messdaten** und **Konfiguration**. Beide Bereiche verfügen über einen eigenen Speicherpfad für die Sicherungsdateien.

#### Backup erstellen

Sichert alle Messdaten des Crawlers als Archiv im konfigurierten Speicherpfad.

| Element | Beschreibung |
|---|---|
| **Nach Zeitraum filtern** | Schalter — wenn aktiviert, können Von- und Bis-Datum/-Uhrzeit eingegeben werden. Nur Messdaten aus diesem Zeitraum werden in das Backup aufgenommen. |
| **Von / Bis** | Zeitraum-Auswahl mit Datepicker. Nur sichtbar, wenn „Nach Zeitraum filtern" aktiviert ist. |
| **Backup starten** | Startet das Backup. Ein Fortschrittsbalken zeigt den Verlauf an. Während des Backups erscheint **Backup abbrechen** als Alternative. |

<div class="screenshot-frame screenshot-frame-sm">

</div>

#### Messdaten wiederherstellen

Stellt Messdaten aus einem vorhandenen Backup wieder her.

| Element | Beschreibung |
|---|---|
| **Aus externem Ordner wiederherstellen…** | Aufklappbarer Bereich — zeigt Backups, die im Speicherpfad gefunden wurden. Jeder Eintrag zeigt Datum, Größe, Pfad, Shards und Messdaten-Zeitraum. Ein Eintrag wird per Klick ausgewählt (blauer Punkt). |
| **Messdaten ersetzen** | Schalter — wenn aktiviert, werden bestehende Messdaten für denselben Zeitraum überschrieben. Wenn deaktiviert, werden die wiederhergestellten Daten ergänzt. |
| **Messdaten wiederherstellen** | Startet die Wiederherstellung. Nur aktiv, wenn ein Backup ausgewählt wurde. |

<div class="screenshot-frame screenshot-frame-sm">
  <img src={backupMessdatenRestoreEntryImg.src} alt="Messdaten wiederherstellen — Backup-Eintrag ausgewählt" />
</div>

#### Konfiguration sichern

Erstellt ein Backup der Gerätekonfiguration. Die zu sichernden Bestandteile können einzeln ausgewählt werden.

| Element | Beschreibung |
|---|---|
| **Date & Time Settings** | Datum- und Zeiteinstellungen des Geräts. |
| **Network Settings** | Netzwerkkonfiguration (IP-Adressen, DNS usw.). |
| **Crawler Settings** | Gerätespezifische Einstellungen des Crawlers. |
| **Node-RED** | Node-RED-Flows und -Konfiguration. |
| **Grafana (Dashboards)** | Grafana-Dashboards. |
| **Login Credentials** | Login-Zugangsdaten des Geräts. |
| **Kommentar (optional)** | Freitextfeld für eine Beschreibung des Backups. |
| **Konfiguration sichern** | Startet die Sicherung. Ein Fortschrittsbalken zeigt den Verlauf an. |

<div class="screenshot-frame screenshot-frame-sm">

#### Konfiguration wiederherstellen

Stellt eine gesicherte Gerätekonfiguration wieder her.

| Element | Beschreibung |
|---|---|
| **Aus externer Datei wiederherstellen…** | Aufklappbarer Bereich — ermöglicht das Hochladen einer Konfigurationsdatei von außerhalb des Speicherpfads. |
| Geräte-Backups | Unter dem Hochladen-Bereich werden vorhandene Backups des Geräts aufgelistet. Ein Backup wird per Klick ausgewählt. |
| **Konfiguration wiederherstellen** | Startet die Wiederherstellung mit dem ausgewählten Backup. Nur aktiv, wenn ein Backup ausgewählt wurde. |

#### Speicherpfad

Zeigt den lokalen Pfad, in dem Konfigurationssicherungen abgelegt werden. Über das Stift-Symbol kann der Pfad geändert werden.
