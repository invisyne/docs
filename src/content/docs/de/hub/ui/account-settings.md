## So gelangen Sie zu Ihren Kontoeinstellungen

Um Ihre persönlichen Daten und Sicherheitseinstellungen zu verwalten, gehen Sie wie folgt vor:

**Schritt 1: Profil öffnen** Klicken Sie oben rechts in der Navigationsleiste auf Ihr Profil-Symbol (die runden Initialen "JG"). Es öffnet sich ein Dropdown-Menü mit verschiedenen Optionen.

**Schritt 2: Kontoeinstellungen wählen** Im aufgeklappten Menü sehen Sie die Option "Kontoeinstellungen" mit einem Zahnrad-Symbol. Klicken Sie darauf, um zur Einstellungsseite zu gelangen.

![](https://api.archbee.com/api/optimize/5QJBvgamF9LtImfLB456o/--SfI4zXwXOKW-n5RhDhK_einstellungen.PNG)

## Verfügbare Einstellungen

Auf der Kontoeinstellungsseite finden Sie zwei Hauptbereiche:

### Persönliche Daten

Hier können Sie folgende Informationen einsehen und bearbeiten:

- **E-Mail-Adresse**: Ihre registrierte E-Mail-Adresse
- **Vorname**: Ihr Vorname
- **Nachname**: Ihr Nachname

Um Änderungen vorzunehmen, klicken Sie auf den Button "Persönliche Daten bearbeiten". Die Felder werden dann editierbar, und Sie können Ihre Angaben anpassen. Speichern Sie Ihre Änderungen mit dem Button "Persönliche Daten speichern".

![](https://api.archbee.com/api/optimize/5QJBvgamF9LtImfLB456o/R0QtrkC805MkbFUcqhr1N_kontoeinstellungen01.PNG)

![](https://api.archbee.com/api/optimize/5QJBvgamF9LtImfLB456o/pn5NpXYW4cHV-01bTmYK6_kontoeinstellungen02.PNG)

### Sicherheit

Im Sicherheitsbereich können Sie Ihr Passwort ändern:

- Ihr aktuelles Passwort wird aus Sicherheitsgründen verdeckt angezeigt (als Sternchen)
- Klicken Sie auf "Passwort bearbeiten", um ein neues Passwort festzulegen

Bei Bedarf können Sie Änderungen mit "Abbrechen" verwerfen, falls Sie Ihre Meinung ändern.
