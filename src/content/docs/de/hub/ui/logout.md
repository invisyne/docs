Oben rechts in der Benutzeroberfläche befindet sich das **Profil-Symbol** (mit den Initialen des Benutzers).
 Wenn man **auf das Profil klickt**, öffnet sich ein **Dropdown-Menü**.

In diesem Menü stehen folgende Optionen zur Verfügung:

- **Kontoeinstellungen**: Zugriff auf persönliche Einstellungen 
- **Logout**: Abmeldung vom Hub 

Um sich auszuloggen, klickt man einfach im geöffneten Menü auf **„Logout“**.
