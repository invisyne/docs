## Übersicht

Navigieren Sie über die obere Navigationsleiste zu **Benutzer**, um alle Konten Ihrer Organisation einzusehen — inklusive Name, E-Mail-Adresse, Rolle und Status.

## Neuen Benutzer anlegen

Administratoren können neue Benutzerkonten direkt auf der Benutzerseite anlegen. Der Account wird ohne Passwort angelegt — der Benutzer erhält erst nach einer Einladung Zugang.

<Steps>
1. Klicken Sie auf die **+**-Schaltfläche, um den Dialog zum Anlegen eines neuen Benutzers zu öffnen.

2. Geben Sie die E-Mail-Adresse sowie Vor- und Nachname ein.

3. Wählen Sie eine Rolle — **Benutzer** oder **Admin**.

4. Klicken Sie auf **Erstellen**.
</Steps>

<div class="screenshot-frame">
  <img src={createUserImg.src} alt="Hub-Dialog zum Anlegen eines neuen Benutzers mit E-Mail, Passwort, Name und Rolle" />
</div>

Um dem neuen Benutzer Zugang zu gewähren, klicken Sie auf **Einladen** neben seinem Eintrag — siehe [Benutzer einladen](/de/hub/how-to/invite-user/).

## Benutzer deaktivieren

Um ein Konto zu deaktivieren, öffnen Sie den Benutzereintrag und klicken Sie auf **Deaktivieren**. Der Zugang wird sofort entzogen. Deaktivierte Konten können jederzeit wieder aktiviert werden.
