## Technische Informationen

### Systemvoraussetzungen

Das Hub ist als webbasierte Anwendung konzipiert und erfordert:

- Moderne Webbrowser (Chrome, Firefox, Safari, Edge)
- Stabile Internetverbindung
- Entsprechende Zugangsberechtigung

### Version

Die aktuelle Version wird im Footer der Anwendung angezeigt:

- UI-Version: 1.0.12
- API-Version: 1.0.17
