Viele Ansichten im Hub verfügen über ein Echtzeit-Suchfeld, Filteroptionen und sortierbare Spalten.

<div class="doc-accordion" id="fs-accordion">
  <div class="doc-accordion-items">
    <div class="doc-accordion-item doc-accordion-active">
      <button class="doc-accordion-title">
        <span>Suchsymbol</span>
        <span class="doc-accordion-arrow">&#x2303;</span>
      </button>
      <div class="doc-accordion-body">
        Das Suchfeld befindet sich oben rechts in der jeweiligen Ansicht — erkennbar am Lupensymbol. Klicken Sie auf das **Suchsymbol**, um das Eingabefeld zu öffnen.

        <div class="qs-tip">Die Suche durchsucht alle sichtbaren Spalten der aktiven Ansicht in Echtzeit.</div>
      </div>
    </div>
    <div class="doc-accordion-item">
      <button class="doc-accordion-title">
        <span>Suchbegriff eingeben</span>
        <span class="doc-accordion-arrow">&#x2303;</span>
      </button>
      <div class="doc-accordion-body">
        Tippen Sie einen Begriff ein — die Liste filtert sich sofort in Echtzeit. Zum Zurücksetzen: **×**-Symbol klicken oder Text löschen.

        <div class="qs-tip">Ein Teilbegriff reicht aus — es werden alle Einträge gefunden, die den Begriff in einer Spalte enthalten.</div>
      </div>
    </div>
    <div class="doc-accordion-item">
      <button class="doc-accordion-title">
        <span>Spalten sortieren</span>
        <span class="doc-accordion-arrow">&#x2303;</span>
      </button>
      <div class="doc-accordion-body">
        Klicken Sie auf einen **Spaltenkopf**, um die Liste nach dieser Spalte zu sortieren. Ein erneuter Klick kehrt die Sortierrichtung um. Der Pfeil (↑ / ↓) neben dem Spaltennamen zeigt die aktive Sortierspalte und -richtung an.

        <div class="qs-tip">Sortierung und Suche funktionieren zusammen — Sie können auch gefilterte Ergebnisse sortieren.</div>
      </div>
    </div>
  </div>
  <div class="doc-accordion-image">
    <div class="doc-acc-img-wrap doc-acc-img-active">
      <img src={filterOpenImg.src} alt="Suchsymbol oben rechts in der Geräteliste" />
    </div>
    <div class="doc-acc-img-wrap">
      <img src={filterActiveImg.src} alt="Geräteliste gefiltert nach Wago" />
    </div>
    <div class="doc-acc-img-wrap">
      <img src={filterSortImg.src} alt="Spaltenkopf mit Sortierpfeil markiert" />
    </div>
  </div>
</div>

<script>{`
if (typeof document !== 'undefined') {
  function initFsAccordion() {
    const acc = document.getElementById('fs-accordion');
    if (!acc || acc.dataset.ready) return;
    acc.dataset.ready = '1';
    const items = Array.from(acc.querySelectorAll('.doc-accordion-item'));
    const imgWraps = Array.from(acc.querySelectorAll('.doc-acc-img-wrap'));
    items.forEach((item, i) => {
      item.querySelector('.doc-accordion-title').addEventListener('click', () => {
        items.forEach((it, j) => {
          it.classList.toggle('doc-accordion-active', j === i);
          if (imgWraps[j]) imgWraps[j].classList.toggle('doc-acc-img-active', j === i);
        });
      });
    });
  }
  initFsAccordion();
  document.addEventListener('astro:page-load', initFsAccordion);
}
`}</script>
