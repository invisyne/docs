## Kontoeinrichtung

Ein Admin legt Ihr Konto an und schickt Ihnen die Zugangsdaten (E-Mail-Adresse und Passwort) zu. Das Passwort können Sie jederzeit in den [Kontoeinstellungen](/de/hub/ui/account-settings/) ändern.

## Anmelden

<Steps>
1. Rufen Sie die Hub-URL in Ihrem Browser auf. Die Anmeldeseite öffnet sich automatisch.

2. Geben Sie Ihre **E-Mail**-Adresse und Ihr **Passwort** in die entsprechenden Felder ein.

3. Klicken Sie auf **Anmelden**, um sich einzuloggen.
</Steps>

<div class="screenshot-frame">
  <img src={loginImg.src} alt="Hub-Anmeldeseite mit E-Mail- und Passwortfeldern" />

<div class="qs-tip">Passwort vergessen? Klicken Sie auf <strong>Passwort vergessen?</strong> auf der Anmeldeseite. Geben Sie Ihre E-Mail-Adresse ein und Sie erhalten einen Link zum Zurücksetzen.</div>

## Sitzung und Abmeldung

Hub meldet Sie nach einer Inaktivitätsphase automatisch ab. Melden Sie sich auf gemeinsam genutzten oder öffentlichen Computern immer manuell ab — klicken Sie dazu oben rechts auf Ihren Initialen-Avatar und wählen Sie **Logout**.

## Benutzerverwaltung

Die Benutzerverwaltung obliegt Administratoren. Sie können neue Teammitglieder einladen, Rollen vergeben und bestehende Konten verwalten. Eine Schritt-für-Schritt-Anleitung finden Sie unter [Neuen Benutzer einladen](/de/hub/how-to/invite-user/).
