Sie können Ihr Passwort jederzeit über Ihre Kontoeinstellungen ändern.

<Steps>
1. **Kontoeinstellungen öffnen** — Klicken Sie auf Ihr Profilsymbol in der rechten oberen Ecke der Navigationsleiste und wählen Sie **Kontoeinstellungen**.

2. **Zum Abschnitt Sicherheit gehen** — Scrollen Sie auf der Einstellungsseite nach unten zum Abschnitt **Sicherheit**.

3. **Passwort bearbeiten klicken** — Klicken Sie auf die Schaltfläche **Passwort bearbeiten**, um das Formular zur Passwortänderung zu öffnen.

4. **Neues Passwort eingeben** — Geben Sie Ihr neues Passwort ein. Wählen Sie ein sicheres Passwort, das Sie nicht woanders verwenden.

5. **Speichern** — Klicken Sie auf **Speichern**. Ihr Passwort wird sofort aktualisiert.
</Steps>
