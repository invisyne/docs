Sie können die Metadaten eines Geräts jederzeit über die Geräteliste ergänzen oder aktualisieren.

<Steps>
1. **Zu Geräte navigieren** — Wählen Sie **Geräte** in der oberen Navigationsleiste.

2. **Gerät öffnen** — Klicken Sie auf die Zeile des zu bearbeitenden Geräts. Das Detailfeld öffnet sich.

3. **Bearbeiten klicken** — Klicken Sie auf die Schaltfläche **Bearbeiten** (Stiftsymbol) im Detailfeld, um den Bearbeitungsmodus zu aktivieren.

4. **Felder ausfüllen** — Ergänzen oder aktualisieren Sie beliebige Felder:

   | Feld | Beschreibung |
   |---|---|
   | **Name** | Ein eindeutiger Bezeichner für das Gerät |
   | **Standort** | Physischer Aufstellungsort des Geräts |
   | **Adresse** | Straßenadresse des Installationsorts |
   | **Kontakt** | Zuständige Person oder Team für dieses Gerät |
   | **Bestellnummer** | Interne Bestellreferenz |
   | **Lieferdatum** | Datum der Lieferung |
   | **Notizen** | Freies Textfeld für weitere Informationen |

5. **Änderungen speichern** — Klicken Sie auf **Speichern**. Die aktualisierten Informationen werden sofort in der Geräteliste angezeigt.
</Steps>
