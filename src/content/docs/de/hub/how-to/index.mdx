## Geräte

<div class="qs-stepper">
  <div class="qs-tabbar">
    <a class="qs-tab" href="#">Filtern, Suchen und Sortieren</a>
    <a class="qs-tab" href="#">Gerät bearbeiten</a>
  </div>
  <div class="qs-panels">

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Filtern, Suchen und Sortieren</div>
        <p class="howto-card-desc">Finden Sie jedes Gerät in Ihrer Flotte schnell über die Suchleiste, Spaltensortierung und Filteroptionen.</p>
        <ol class="howto-steps-preview">
          <li>Öffnen Sie <strong>Geräte</strong> in der oberen Navigationsleiste.</li>
          <li>Tippen Sie in das Suchfeld — Übereinstimmungen nach Name, Seriennummer, Ort und Firmware-Version.</li>
          <li>Klicken Sie auf eine Spaltenüberschrift, um auf- oder absteigend zu sortieren.</li>
          <li>Klicken Sie auf das Filter-Symbol, um Ergebnisse nach Typ, Ort oder Firmware-Version einzugrenzen.</li>
          <li>Klicken Sie auf <strong>Alle zurücksetzen</strong>, um alle aktiven Filter zu löschen.</li>
        </ol>

      </div>
    </div>

    <div class="qs-panel">

        <div class="howto-card-title">Geräteinformationen bearbeiten</div>
        <p class="howto-card-desc">Metadaten eines Geräts ergänzen oder aktualisieren — Name, Standort, Adresse, Kontakt, Bestellnummer und mehr.</p>
        <ol class="howto-steps-preview">
          <li>Öffnen Sie <strong>Geräte</strong> in der oberen Navigationsleiste.</li>
          <li>Klicken Sie auf eine Gerätezeile, um das Detailfeld zu öffnen.</li>
          <li>Klicken Sie auf die Schaltfläche <strong>Bearbeiten</strong> (Stiftsymbol).</li>
          <li>Ergänzen oder aktualisieren Sie die gewünschten Felder.</li>
          <li>Klicken Sie auf <strong>Speichern</strong>.</li>
        </ol>

## Benutzer <span class="howto-admin-badge">nur Admins</span>

<div class="qs-stepper">
  <div class="qs-tabbar">
    <a class="qs-tab" href="#">Benutzer anlegen</a>
    <a class="qs-tab" href="#">Rolle ändern</a>
  </div>
  <div class="qs-panels">

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Neuen Benutzer anlegen</div>
        <p class="howto-card-desc">Neues Benutzerkonto in Hub anlegen und eine Rolle zuweisen.</p>
        <ol class="howto-steps-preview">
          <li>Gehen Sie zu <strong>Benutzer</strong> in der oberen Navigationsleiste.</li>
          <li>Klicken Sie auf die Schaltfläche <strong>+</strong>.</li>
          <li>Geben Sie die E-Mail-Adresse des neuen Benutzers ein.</li>
          <li>Wählen Sie eine Rolle: <strong>Admin</strong> oder <strong>Benutzer</strong>.</li>
          <li>Klicken Sie auf <strong>Anlegen</strong> — das Konto ist sofort aktiv.</li>
        </ol>
        <a href="/de/hub/how-to/invite-user/" class="howto-cta">Zur vollständigen Anleitung →</a>
      </div>
    </div>

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Benutzerrolle ändern</div>
        <p class="howto-card-desc">Einen Benutzer zum Admin befördern oder einen Admin zum Benutzer herabstufen — wirksam beim nächsten Seitenaufruf.</p>
        <ol class="howto-steps-preview">
          <li>Gehen Sie zu <strong>Benutzer</strong> in der oberen Navigationsleiste.</li>
          <li>Suchen Sie den Benutzer in der Liste (Name oder E-Mail).</li>
          <li>Klicken Sie auf die Zeile des Benutzers, um sein Profil zu öffnen.</li>
          <li>Wählen Sie die neue Rolle in der Dropdown-Liste: <strong>Admin</strong> oder <strong>Benutzer</strong>.</li>
          <li>Klicken Sie auf <strong>Speichern</strong>, um die Änderung zu übernehmen.</li>
        </ol>
        <a href="/de/hub/how-to/change-role/" class="howto-cta">Zur vollständigen Anleitung →</a>
      </div>
    </div>

## Kontoeinstellungen

<div class="qs-stepper">
  <div class="qs-tabbar">
    <a class="qs-tab" href="#">Passwort ändern</a>
    <a class="qs-tab" href="#">Sprache wechseln</a>
  </div>
  <div class="qs-panels">

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Passwort ändern</div>
        <p class="howto-card-desc">Eigenes Passwort direkt über die Kontoeinstellungen aktualisieren.</p>
        <ol class="howto-steps-preview">
          <li>Klicken Sie auf Ihr <strong>Profilsymbol</strong> in der rechten oberen Ecke.</li>
          <li>Wählen Sie <strong>Kontoeinstellungen</strong> aus dem Dropdown-Menü.</li>
          <li>Klicken Sie auf <strong>Passwort ändern</strong>.</li>
          <li>Geben Sie Ihr aktuelles Passwort ein, dann das neue Passwort zweimal.</li>
          <li>Klicken Sie auf <strong>Speichern</strong> — das neue Passwort gilt sofort.</li>
        </ol>
        <a href="/de/hub/how-to/change-password/" class="howto-cta">Zur vollständigen Anleitung →</a>
      </div>
    </div>

    <div class="qs-panel">
      <div class="howto-card">
        <div class="howto-card-title">Sprache wechseln</div>
        <p class="howto-card-desc">Hub zwischen Deutsch und Englisch umstellen — die Einstellung wird im Browser gespeichert.</p>
        <ol class="howto-steps-preview">
          <li>Klicken Sie auf Ihr <strong>Profilsymbol</strong> in der rechten oberen Ecke.</li>
          <li>Wählen Sie <strong>Kontoeinstellungen</strong>.</li>
          <li>Suchen Sie die Einstellung <strong>Sprache</strong>.</li>
          <li>Wählen Sie <strong>Deutsch</strong> oder <strong>English</strong>.</li>
          <li>Klicken Sie auf <strong>Speichern</strong> — die Oberfläche wechselt sofort die Sprache.</li>
        </ol>
        <a href="/de/hub/how-to/change-language/" class="howto-cta">Zur vollständigen Anleitung →</a>
      </div>
    </div>

  </div>
