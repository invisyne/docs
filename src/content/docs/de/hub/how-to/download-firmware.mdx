---

import { Steps } from '@astrojs/starlight/components';

<a href="/de/hub/how-to" class="guide-back-link">← Anleitungen</a>

Firmware-Dateien für Edge (Crawler)-Geräte sind direkt in Hub im Bereich Software verfügbar.

<Steps>
1. **Zu Software navigieren** — Klicken Sie auf **Software** in der oberen Navigationsleiste.

2. **Gewünschte Version finden** — Durchsuchen Sie im Abschnitt **Crawler** die Liste der verfügbaren Firmware-Versionen. Die Versionen werden neueste zuerst angezeigt.

3. **Herunterladen** — Klicken Sie auf die Schaltfläche **Herunterladen** neben der gewünschten Version. Die Firmware-Datei wird am Standard-Download-Speicherort Ihres Browsers gespeichert.
</Steps>
