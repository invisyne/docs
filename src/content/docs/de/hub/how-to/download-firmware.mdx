<a href="/de/hub/how-to" class="guide-back-link">← Anleitungen</a>

Firmware-Dateien für Edge-Geräte sind direkt in Hub im Bereich Software verfügbar.

<Steps>
1. **Zu Software navigieren** — Klicken Sie auf **Software** in der oberen Navigationsleiste.

2. **Gewünschte Version finden** — Durchsuchen Sie im Abschnitt **Crawler** die Liste der verfügbaren Firmware-Versionen. Die Versionen werden neueste zuerst angezeigt.

3. **Detailseite öffnen** — Klicken Sie auf den Versionseintrag, um die Detailseite zu öffnen. Dort finden Sie Release-Notes und weitere Informationen zum Release.

4. **Herunterladen** — Klicken Sie auf der Detailseite auf die Schaltfläche **Herunterladen**, um die Firmware-Datei herunterzuladen. Sie wird am Standard-Download-Speicherort Ihres Browsers gespeichert.
</Steps>
