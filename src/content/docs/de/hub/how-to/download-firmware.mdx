---
title: "Software herunterladen"
description: "So laden Sie Edge-Firmware-Dateien und den Crawler.Companion-Installer aus Hub herunter."
---

import { Steps } from '@astrojs/starlight/components';

Hub stellt Firmware-Dateien für Edge-Geräte sowie Installer für Crawler.Companion bereit. Beides ist im Bereich Software verfügbar.

<Steps>
1. **Zu Software navigieren** — Klicken Sie auf **Software** in der oberen Navigationsleiste.

2. **Gewünschte Version finden** — Durchsuchen Sie die verfügbaren Versionen. Der Abschnitt **Crawler** enthält Edge-Firmware, der Abschnitt **Companion** enthält Crawler.Companion-Installer. Die Versionen werden neueste zuerst angezeigt.

3. **Detailseite öffnen** — Klicken Sie auf einen Versionseintrag, um die Detailseite mit Release-Notes und weiteren Informationen zu öffnen.

4. **Herunterladen** — Klicken Sie auf **Herunterladen**, um die Datei am Standard-Download-Speicherort Ihres Browsers zu speichern. Je nach Release stehen Vollversionen und Patches zum Download bereit.
</Steps>
