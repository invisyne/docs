<a href="/de/hub/how-to" class="guide-back-link">← Anleitungen</a>

:::note
Diese Aktion erfordert die Rolle **Admin**.
:::

Laden Sie Teammitglieder zu Hub ein, indem Sie ihnen direkt von der Benutzerseite eine E-Mail mit Zugangsdaten senden.

<Steps>
1. **Zu Benutzer navigieren** — Klicken Sie auf **Benutzer** in der oberen Navigationsleiste.

2. **+ Schaltfläche klicken** — Klicken Sie auf die Schaltfläche **+**, um den Einladungsdialog zu öffnen.

3. **E-Mail-Adresse eingeben** — Geben Sie die E-Mail-Adresse des neuen Benutzers in das Eingabefeld ein.

4. **Rolle auswählen** — Wählen Sie entweder **Admin** (voller Zugriff einschließlich Benutzerverwaltung) oder **Benutzer** (Standardzugriff auf Geräte und Software).

5. **Einladung bestätigen** — Klicken Sie auf **Einladen**. Der neue Benutzer erhält eine E-Mail mit seinen Zugangsdaten.
</Steps>
