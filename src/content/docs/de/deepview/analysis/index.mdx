## Bestehendes Projekt öffnen

1. Sucht auf dem Startbildschirm das gewünschte Projekt in der Projektliste
2. Wählt die Daten aus, die ihr visualisieren möchtet
3. Klickt auf **Open with selected data**

{/* Screenshot: Projektliste mit ausgewähltem Projekt, "Open with selected data" sichtbar */}

## Neues Projekt starten

Um ganz neu zu beginnen, klickt unten links auf **New Project**. Das öffnet ein leeres Projekt ohne Plots — wie ihr Daten hineinladet, steht unter [Add Data Sets](/de/deepview/analysis/add-data-sets).

{/* Screenshot: "New Project"-Button, unten links im Bildschirm */}

Hintergrund dazu, was ein Projekt genau ist (und wie es sich von einer einzelnen Visualisierung unterscheidet): [Projects](/de/deepview/projects).
