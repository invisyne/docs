## Overview

Visualisierungen werden in Tabs organisiert. Gute Namen erleichtern es, Daten später wiederzufinden.

![](../../../../../assets/images/deepview/deepview-analysis-tabs-1.png)

Klickt auf die drei Punkte neben einem Tab, um ihn:

- zu duplizieren,
- umzubenennen oder
- zu löschen.

Um einen Tab hinzuzufügen, klickt auf das **+**-Zeichen am Ende der Tab-Liste.

## Tabs neu anordnen

Um Tabs neu anzuordnen, zieht einen Tab per Drag-and-Drop an die gewünschte Stelle.

![](../../../../../assets/images/deepview/deepview-analysis-tabs-2.gif)


## Tabs gruppieren

Ihr könnt zusammengehörige Tabs zu Gruppen zusammenfassen.

- Klickt auf die drei Punkte neben einem Tab-Namen, um ihn einer neuen oder bestehenden Gruppe hinzuzufügen.
- Zieht einen Tab in eine Gruppe, um ihn aufzunehmen.
- Gebt jeder Gruppe einen Namen und eine Farbe, damit ihr sie leicht wiederfindet.
