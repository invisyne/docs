Über das reine Visualisieren von Rohsignalen hinaus könnt ihr Functions auf Signale — oder Kombinationen von Signalen — anwenden, um eigene Varianten zu erstellen. So lassen sich Berechnungen direkt im Analysefluss durchführen, ohne den Originaldatensatz zu verändern.

- [Functions Overview](/de/deepview/analysis/functions/functions-overview) — wo Functions in der Oberfläche zu finden und hinzuzufügen sind
- [Built-in functions](/de/deepview/analysis/functions/built-in-functions) — die vorgefertigten Functions, die direkt verfügbar sind
- [Custom functions](/de/deepview/analysis/functions/custom-functions) — eigene Functions schreiben
