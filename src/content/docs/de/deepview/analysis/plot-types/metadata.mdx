Der **Metadata Plot** zeigt die Metadaten des aktuell geöffneten Datensatzes — nützlich, um genau zu wissen, welche Informationen an ihm hängen.

![](../../../../../../assets/images/deepview/deepview-analysis-plot-types-metadata-1.png)

Ihr könnt den Metadata Plot auch in anderen Deepview-Tools nutzen, etwa in Reports oder bei [Export image](/de/deepview/analysis/export-image). Er kann zwei Arten von Text anzeigen:

- **Metadata** — ändert sich dynamisch anhand der Metadaten eures Datensatzes, z. B. Maschine, Bediener, Testname
- **Static Text** — bleibt gleich und ändert sich anhand des geöffneten Projekts, z. B. Projektname, Verification Phase, Main Editor

## Einstellungen

Erreichbar über das Einstellungsrad oben rechts im Plot:

- **Title** — Standard ist "Metadata Plot"
- **Columns** — hat einen "Auto"-Schalter oder eine manuelle Zahleneingabe
- **Box** — zeigt den Metadata Plot in einem umrahmten Format an
- **Field & Value** — item-spezifische Einstellungen; hier könnt ihr z. B. den Text eines Static-Text-Eintrags bearbeiten
- **Add + buttons** — fügt eine neue Zeile mit Metadata oder Static Text hinzu
