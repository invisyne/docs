## Y-Achsen-Modi

Die Einstellung **Axis mode** in den Plot-Einstellungen wechselt zwischen zwei Modi:

- **Simple** (Standard) — alle Signale werden unter einer Y-Achse gruppiert, die dynamisch auf die sichtbaren Daten zoomt.
- **Advanced** — schaltet die übrigen Y-Achsen-Einstellungen frei.

Ein Klick auf **Stack all signals** oder den Unstack-Button daneben in der Toolbar wechselt ebenfalls zu Advanced.

## Achseneinstellungen des Plots

Die Axes-Einstellungen befinden sich in den Plot-Einstellungen:

- **Axis mode** — **Simple** oder **Advanced**
- **Autoscale axes** — die Y-Achse jedes Signals skaliert automatisch auf die aktuell sichtbaren Daten
- **Show all X axes** — die X-Achse jedes Datensatzes statt nur der ersten anzeigen (nur verfügbar beim Vergleichen von Datensätzen)
- **Show all Y axes** — die Y-Achse jeder verknüpften Signalgruppe anzeigen

## X-Achsen-Modi

Je nach Daten zeigt die X-Achse die Zeit in einem von zwei Modi:

- **Absolute time** — enthalten die Daten echte Timestamps, werden sie standardmäßig in der lokalen Zeitzone eures Browsers angezeigt. Klickt oben rechts auf das Globus-Symbol, um eine andere Zeitzone zu wählen.
- **Relative time** — klickt auf den Stoppuhr-Button, um stattdessen Sekunden seit Beginn der Daten anzuzeigen. Die Daten beginnen dann bei 0 s.
