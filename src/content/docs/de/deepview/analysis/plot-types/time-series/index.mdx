Der Time-Series-Plot ist der Standard-Plot-Typ und der vielseitigste: Visualisiert mehrere Signale in einem Plot, um zu sehen, wie sie korrelieren. Wählt so viele Signale aus, wie ihr möchtet — siehe [Signal List](/de/deepview/analysis/signal-list).

## Signale plotten

Sobald Signale zu einem Time-Series-Plot hinzugefügt wurden, erscheinen sie in einem Panel links vom Plot. Jedes Signal erhält eine Standardfarbe und wird mit Signalen gruppiert, die dieselben Limits oder dieselbe Y-Achse teilen.

{/* Screenshot: Time-Series-Plot mit Signal-Panel links, Signale nach Farbe gruppiert */}

## Signale auswählen

Klickt ihr ein Signal an, das Teil einer Signalgruppe ist, wird die ganze Gruppe ausgewählt — der Hintergrund der gruppierten Signale wird grau, mit einer durchgezogenen Linie daneben. Klickt das Signal erneut an, um die Einstellungen nur dieses einzelnen Signals zu ändern.
