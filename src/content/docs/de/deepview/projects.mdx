## Overview

Mit Projects in Deepview könnt ihr Plot-Layouts, Tabs und andere Visualisierungskonfiguration speichern, um sie in künftigen Sitzungen einfach wiederzufinden. Ihr könnt Projects außerdem mit eurem Team teilen.

Einen Überblick über alle Projects, an denen euer Team gearbeitet hat, findet ihr auf der Deepview-Startseite. Für jedes Project seht ihr außerdem:

- Datum und Uhrzeit der letzten Speicherung
- Mitwirkende am Project
- Mit dem Project verknüpfte Datensätze
- Ob das Project [Read-Only](#read-only) ist

![](../../../../assets/images/deepview/deepview-projects-1.png)

In der Visualisierungsansicht seht ihr unten links im Fenster Informationen zum Project, an dem ihr gerade arbeitet.

![](../../../../assets/images/deepview/deepview-projects-2.png)

## Datensätze in Projects laden

Um ein Project zu öffnen, klickt auf **Open** neben dem Project in der Liste der zuletzt verwendeten Projects auf der Startseite.

![](../../../../assets/images/deepview/deepview-projects-3.png)

Bevor das Project lädt, werdet ihr aufgefordert auszuwählen, welche Daten aus eurer letzten Sitzung ihr neu laden möchtet.

![](../../../../assets/images/deepview/deepview-projects-4.png)

Ihr könnt zuvor geladene Daten auch neu laden, indem ihr auf **Show History** klickt und die gewünschten Datensätze für das Project auswählt.

![](../../../../assets/images/deepview/deepview-projects-5.png)

Wollt ihr ein Project sofort leer öffnen, klickt in der Liste der zuletzt verwendeten Projects auf **Open empty**.

![](../../../../assets/images/deepview/deepview-projects-6.png)

## Wann Projects nutzen

Nutzt Projects, wenn ihr mehrere Datensätze aus derselben Quelle oder demselben Logger analysiert.

Ein Project speichert eure Plot-Layouts, ausgewählten Signale, Signal-Reihenfolge und sogar berechnete Signale. Einmal eingerichtet, könnt ihr dieselbe Analyse sofort auf neue Datensätze anwenden — Deepview übernimmt eure Berechnungen automatisch für eine nahtlose Datenexploration.

## Read-Only

Standardmäßig können Projects in Deepview von jedem in eurem Workspace bearbeitet werden, was die Zusammenarbeit erleichtert.

Wollt ihr Bearbeitungen einschränken, könnt ihr ein Project auf **Read-Only** setzen. Dann könnt nur ihr Änderungen vornehmen und speichern, während andere nur ansehen, aber nicht bearbeiten können — Änderungen anderer werden nicht gespeichert.

Um den Read-Only-Modus zu aktivieren, aktiviert beim Speichern eines neuen Projects die Option **Read-Only**.
