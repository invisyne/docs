## Warum DeepView

Die Analyse hochfrequenter Mess- und Testdaten bedeutet für Ingenieure meist: eigene Skripte schreiben, um eine Datei zu laden, ein paar Signale zu plotten — und das für jede neue Frage von vorn. DeepView ersetzt das durch einen webbasierten Arbeitsbereich speziell für Zeitreihendaten: einmal verbinden, danach interaktiv erkunden — kein erneutes Ausführen von Skripten für jede neue Frage.

DeepView liest Daten direkt aus den Datenbanken hinter Hub — zwischen der Aufzeichnung eines Signals auf dem Edge-Gerät und seiner Analyse liegt kein separater Export- oder Dateiübertragungsschritt.

## Für wen DeepView gedacht ist

DeepView ist für Ingenieure und Service-Teams gebaut, die mit Sensordaten industrieller Maschinen arbeiten — Inbetriebnahmeingenieure, die eine neue Installation validieren, Service-Techniker bei der Fehlerdiagnose, oder Engineering-Leads, die die Performance über eine Maschinenflotte hinweg vergleichen.

## Häufige Fragen

<details>
<summary>Welche Datenquellen unterstützt DeepView?</summary>

DeepView greift auf die Zeitreihen- und Asset-Daten zu, die Hub verwaltet. Es gibt nichts einzurichten — eure Daten sind bereits verbunden, sobald ihr DeepView öffnet.

</details>

<details>
<summary>Kann ich Daten mehrerer Maschinen in einer Ansicht kombinieren?</summary>

Ja — DeepView ist darauf ausgelegt, Signale mehrerer Edge-Geräte in dieselbe Analyse einzubeziehen, sodass ihr eine gesamte Anlage statt nur eine einzelne Maschine vergleichen könnt.

</details>

<details>
<summary>Nutzt DeepView KI?</summary>

DeepView bietet KI-gestützte Funktionen, etwa das automatische Vorschlagen passender Visualisierungen basierend auf der aktuellen Ansicht sowie die direkte Beantwortung von Fragen zu den Daten. Diese Funktionen werden laufend erweitert.

</details>
