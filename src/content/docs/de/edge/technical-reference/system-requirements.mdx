In Netzwerken mit einem Echtzeit-Bus (z. B. PROFINET) werden Edge-Datenpakete mit niedriger Priorität behandelt und können gegenüber dem Echtzeit-Verkehr verzögert sein. Dies kann die Genauigkeit der konfigurierten Abtastintervalle beeinflussen.
:::
