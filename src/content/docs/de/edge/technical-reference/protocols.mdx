#### Adressformate für manuelle Eingabe

Werden Messgrößen manuell über das UI oder per CSV eingegeben, gelten folgende Adressformate.

**Absolute Adressierung**

Aufbau: `DB<Nr>.DB<B|W|D|X><ByteOffset>.<BitOffset>`

<ul>
  <li>Der Operandentyp (DBB, DBD, DBX, DBW) kann beliebig verwendet werden — er dient nur der Lesbarkeit</li>
  <li>Der Bit-Offset ist optional und kann inkl. des trennenden Punkts weggelassen werden</li>
  <li>Leerzeichen müssen entfernt werden</li>
</ul>

Beispiele: `DB9.DBX200.2` (Bit 2 von Byte 200 in DB 9), `DB30.DBW558` (Byte 558 in DB 30)

**Symbolische Adressierung**

Aufbau: `PLC.Blocks.<Datenblock>.<Variable>`, beginnt immer mit `PLC.Blocks.`

<ul>
  <li>Namen mit einem Punkt im Namen müssen in doppelte Anführungszeichen gesetzt werden: <code>"Mein.Name"</code></li>
  <li>Ein doppeltes Anführungszeichen im Namen wird durch Verdopplung maskiert: <code>"Mein""Name"</code></li>
  <li>Groß-/Kleinschreibung beachten</li>
</ul>

Beispiele: `PLC.Blocks.TestDB.MeineVariable`, `PLC.Blocks.TestDB."Meine.Struktur".Variable`, `PLC.Blocks.TestDB.Array.Element[28]`

:::note
Ungültige Adressen — wie sie bei manueller Eingabe häufig entstehen — verhindern den Datenzugriff ohne Fehlermeldung. Die Import-Funktion umgeht dieses Problem: Variablen werden automatisch korrekt formatiert und maskiert.
:::
