Ab Edge 2.22 wird die Weboberfläche standardmäßig über HTTPS bereitgestellt, und über unverschlüsseltes HTTP eingehende Anfragen werden auf HTTPS umgeleitet. Für Umgebungen, in denen HTTPS unpraktikabel ist, ermöglicht die Einstellung **HTTP erlauben**, die Oberfläche zusätzlich über HTTP bereitzustellen. Sie ist **standardmäßig deaktiviert** und sollte nur bewusst aktiviert werden. Hintergründe zum standardmäßigen HTTPS-Verhalten finden Sie unter [Sicherheit: Zertifikate](/de/edge/technical-reference/security-certificates).

HTTP wird **zusätzlich** zu HTTPS bereitgestellt, nicht anstelle davon:

- **HTTP erlauben aus (Standard):** Über HTTP eingehende Anfragen werden auf HTTPS umgeleitet, sodass der gesamte Datenverkehr verschlüsselt ist.
- **HTTP erlauben ein:** Über HTTP eingehende Anfragen werden über HTTP bedient, während HTTPS weiterhin wie bisher funktioniert. Clients, die sich über HTTP verbinden, werden lediglich nicht mehr umgeleitet.

:::note
**Das Erlauben von HTTP deaktiviert die Transportverschlüsselung für HTTP-Verbindungen. Machen Sie sich die Risiken bewusst, bevor Sie es aktivieren.**

- **Alles wird im Klartext übertragen** — Anmeldedaten, Sitzungs-Tokens, Konfiguration und über HTTP gesendete Daten können von jedem im Netzwerk gelesen werden.
- **Datenverkehr kann verändert werden** — ohne Verschlüsselung kann jemand im Netzwerk den Verkehr zwischen Browser und Gerät unbemerkt abfangen und verändern.
- **Die Identität des Geräts wird nicht überprüft** — der Browser kann nicht bestätigen, dass er tatsächlich mit dem Edge-Gerät kommuniziert.
- **Compliance** — Verschlüsselung bei der Übertragung ist häufig eine regulatorische oder beschaffungsseitige Anforderung für Industrieausrüstung (zum Beispiel IEC 62443 oder NIS2); unverschlüsseltes HTTP erfüllt diese möglicherweise nicht.

Aktivieren Sie HTTP nur in vollständig isolierten Netzwerken, in denen diese Risiken akzeptabel sind, und treffen Sie die Entscheidung gemeinsam mit Ihrer **IT- oder Sicherheitsabteilung**. Im Zweifelsfall bleiben Sie bei HTTPS und installieren stattdessen ein Zertifikat — siehe [Eigenes HTTPS-Zertifikat installieren](/de/edge/how-to/https-certificate).
:::

:::note
Beim Wechsel zwischen HTTPS und HTTP müssen Sie sich erneut anmelden — der Browser speichert die Sitzung für jedes Protokoll getrennt.
:::

## HTTP aktivieren

### Über die Einstellungen

<Steps>

1. Die Edge-Weboberfläche öffnen und anmelden.

2. Zu **Einstellungen** → **Netzwerkadapter** wechseln und die Einstellung **HTTP erlauben** suchen.

   <div class="screenshot-frame"><img src={allowHttp.src} alt="Der Schalter HTTP erlauben in Einstellungen, Netzwerkadapter" /></div>

3. **HTTP erlauben** einschalten. Eine Sicherheitswarnung erscheint — lesen Sie sie und bestätigen Sie, dass Sie die Risiken akzeptieren. Die Einstellung wird sofort übernommen; ein separates Speichern ist nicht erforderlich.

4. Es erscheint eine Schaltfläche **WebUI mit HTTP neu laden**. Klicken Sie darauf, um die aktuelle Browsersitzung auf HTTP umzustellen, oder ändern Sie in der Adresszeile einfach `https://` zu `http://`.

</Steps>

### Über den Setup-Assistenten (bei der Ersteinrichtung)

<Steps>

1. Den Setup-Assistenten für das Edge-Gerät starten.

2. Im Schritt **Netzwerkadapter** **HTTP erlauben** einschalten und die Sicherheitswarnung bestätigen.

3. Den Assistenten fortsetzen und abschließen.

</Steps>

## Zurück zu ausschließlich HTTPS wechseln

Um zu ausschließlichem HTTPS-Zugriff zurückzukehren, schalten Sie **HTTP erlauben** an derselben Stelle wieder aus. Über HTTP eingehende Anfragen werden dann wie zuvor auf HTTPS umgeleitet.

Für eine saubere HTTPS-Verbindung ohne Zertifikatswarnung installieren Sie ein Zertifikat, dem Ihre Rechner vertrauen — siehe [Eigenes HTTPS-Zertifikat installieren](/de/edge/how-to/https-certificate).
