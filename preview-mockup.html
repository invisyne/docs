Hub

Hub-Übersicht

Crawler.Hub ist eine webbasierte Verwaltungsplattform für registrierte Edge (Crawler)-Geräte. Nutzer behalten den Überblick über alle Geräte, Firmware-Versionen und Software-Downloads — ohne direkten Gerätezugriff. Zugriff und Sichtbarkeit richten sich nach der zugewiesenen Rolle.

Funktionsumfang

Jeder Account hat eine Rolle — entweder User oder Admin. Admins können zusätzlich neue Benutzer innerhalb ihrer Organisation anlegen und Rollen vergeben.

User
Geräte

Übersicht aller registrierten Edge (Crawler)-Geräte mit Seriennummer, Name, Typ, Ort und Firmware-Version. Ein Klick öffnet die Detailansicht.*

Software

Aktuelle und ältere Firmware- sowie Companion-App-Versionen auf einen Blick. Je Version sind neue Features aufgelistet, inklusive Links zu Dokumentation, Changelog und Download.

Kontoeinstellungen

Persönliche Daten wie Name und E-Mail-Adresse bearbeiten sowie das Passwort ändern.

* Name, Ort, Bestellnummer, Lieferdatum und Notizen können in der Detailansicht bearbeitet werden.

Admin
Benutzerverwaltung

Neue Benutzer per E-Mail einladen und ihnen eine Rolle zuweisen (Admin oder User). Bestehende Zugänge innerhalb der eigenen Organisation verwalten.

Sicherheit

Session-Timeout

Hub meldet Sie nach Inaktivität automatisch ab. Auf gemeinsam genutzten Geräten bitte manuell abmelden.

Zwei-Faktor-Authentifizierung

Beim Login wird ein Bestätigungscode per E-Mail versendet.

Rollenbasierter Zugriff

Jeder Nutzer sieht nur die Funktionen, die seiner Rolle zugewiesen sind.

HTTPS

Hub ist ausschließlich über eine verschlüsselte HTTPS-Verbindung erreichbar.
